6.1 贷后管理体系总览
================================================================================

一、贷后管理的定位

  贷后管理是信贷全生命周期的最后一道防线，也是传统银行最薄弱的环节。
  新一代信贷系统的核心价值之一就是"强化贷后管理"。

  贷后管理覆盖贷款发放后到贷款结清（或核销）的全过程：
    放款 → 资金用途监控 → 日常监控 → 定期检查 
      → 风险预警 → 五级分类 → 到期回收 / 逾期催收 → 核销

二、贷后管理的三道防线

  第一道防线：客户经理（前台）
    - 贷后日常监控
    - 定期现场检查
    - 风险预警信号发现与初核
    - 到期回收管理
    - 逾期初期催收

  第二道防线：风险管理部（中台）
    - 风险预警模型运行与信号推送
    - 风险排查组织
    - 五级分类审核
    - 重大风险处置指导
    - 风险报告

  第三道防线：审计部
    - 贷后管理有效性审计
    - 五级分类准确性审计
    - 拨备充足性审计

三、贷后管理的"六个到位"

  监管部门要求的贷后管理标准：
  1. 资金用途监控到位 —— 防范资金挪用
  2. 经营状况跟踪到位 —— 掌握客户最新情况
  3. 担保物价值监测到位 —— 确保第二还款来源有效
  4. 风险预警响应到位 —— 发现信号及时核实处置
  5. 到期回收管理到位 —— 提前提醒、按期收回
  6. 不良处置跟进到位 —— 积极催收、及时核销

6.2 贷后日常监控
================================================================================

一、监控内容

  1.1 资金用途监控

    受托支付：
      - 放款资金是否按约定支付给交易对手
      - 交易对手与合同是否一致
      - 金额是否与用款计划一致

    自主支付：
      - 借款人事后提供支付凭证（合同、发票）
      - 汇总分析资金流向，发现异常立即核查

    禁止性用途监控：
      - 贷款资金是否流入股市、楼市
      - 是否用于偿还其他银行借款（"以贷还贷"）
      - 是否转入关联方或个人账户

  1.2 经营状况跟踪

    对公客户：
    - 财务数据定期收集（月度/季度/年度）
    - 财务指标变化趋势分析（与历史、行业对比）
    - 订单开工、产销量、价格变化
    - 银行账户流水分析（销售收入回款匹配度）
    - 上下游变化（核心客户流失、供应商催款）

    零售客户：
    - 收入稳定性（社保/公积金缴纳连续性）
    - 征信报告定期查询
    - 还款行为监控

  1.3 征信监控

    - 他行贷款还款情况
    - 征信查询次数激增（多头借贷信号）
    - 新增对外担保
    - 征信报告中新增负面信息

  1.4 外部信息监控

    - 工商信息变更（法人代表、股东、经营范围变更）
    - 司法涉诉（作为被告诉讼、资产查封冻结）
    - 税务异常（欠税、非正常户）
    - 行政处罚
    - 负面舆情（新闻、社交媒体）

  1.5 担保物监控

    - 抵质押物价值波动（盯市）
    - 抵质押物状态（是否损毁、查封）
    - 抵质押物保险到期续保
    - 保证人经营及信用状况变化

二、定期检查制度

  2.1 检查频率

    首次跟踪检查：放款后15-30日内
    日常检查：每季度不少于一次
    重点检查：出现风险信号时

    按客户风险等级调整检查频率：
    - 正常类：每季度1次
    - 关注类：每月1次，并制定风险化解方案
    - 不良类：逐户制定处置方案，持续跟进

  2.2 检查方式

    非现场检查（远程）：
    - 财务报表分析
    - 征信查询
    - 外部公开信息查询
    - 账户流水分析

    现场检查（实地）：
    - 走访经营场所
    - 查看生产/库存/人员状况
    - 与企业管理层访谈
    - 核查抵质押物实物状态

  2.3 检查报告

    每次检查形成书面报告：
    - 客户最新经营状况
    - 财务状况变化分析
    - 担保物状况
    - 风险信号及判断
    - 风险化解措施及计划

三、新一代系统的贷后监控数字化

  传统：客户经理手工收集信息、撰写报告，费时费力且主观性大。

  新一代能力：
  - 自动化数据采集：系统自动调取征信、工商、司法、税务等外部数据
  - 智能财务报表分析：OCR识别 + 自动勾稽 + 异常检测
  - 账户流水智能分析：回款匹配度、资金异常流向识别
  - 贷后任务自动派发和管理（任务到期提醒、完成率统计）
  - 贷后报告模板化生成，客户经理只需确认和补充

6.3 风险预警体系
================================================================================

一、风险预警的定义与目标

  风险预警是银行通过内外部信号监测，提前识别可能影响贷款偿还的风险因素，
  并采取预防性措施的主动风险管理手段。

  目标：从"事后灭火"转向"事前预警"，降低实际损失。

二、预警信号分类

  2.1 财务类预警信号

    【红色信号】（高度危险）
    - 连续两年亏损
    - 经营性现金流持续为负
    - 资产负债率 > 行业均值 + 20% 且持续上升
    - 审计报告出具"否定意见"或"无法表示意见"
    - 财务造假或信息重大不实

    【橙色信号】（中度危险）
    - 收入下降 > 20% 或净利润下降 > 30%
    - 应收账款周转天数显著增加（> 50%）
    - 存货周转天数显著增加（> 50%）
    - 银行借款大幅增加（> 50%）
    - 利息保障倍数 < 1.5

    【黄色信号】（低度关注）
    - 收入/利润小幅下降（< 10%）
    - 财务指标略微恶化
    - 财务报告延迟报送

  2.2 经营类预警信号

    【红色】
    - 停产、半停产
    - 核心高管失联或被抓
    - 企业申请破产或进入破产保护
    - 被吊销营业执照

    【橙色】
    - 主要客户流失
    - 核心技术人员离职
    - 停产检修或限产
    - 经营模式发生重大变化

    【黄色】
    - 管理层不和传闻
    - 员工工资延迟发放
    - 供应商催款
    - 产品抽查不合格

  2.3 信用类预警信号

    【红色】
    - 列入失信被执行人名单
    - 贷款逾期 > 90天
    - 被多家银行起诉
    - 大额资产被查封冻结

    【橙色】
    - 贷款逾期 30-90天
    - 他行贷款展期或重组
    - 征信报告出现不良记录
    - 对外担保金额巨大

    【黄色】
    - 征信查询次数激增
    - 信用卡使用率 > 80%
    - 贷款付息延迟（未超30天）

  2.4 外部环境预警信号

    - 行业政策突变（如房地产调控升级）
    - 行业景气度大幅下滑
    - 区域经济恶化
    - 重大自然灾害

三、预警信号处理流程

  信号发现 → 信号推送 → 核实确认 → 风险定级 → 制定处置方案 → 执行跟踪

  3.1 信号发现
    - 系统自动监测（模型识别）
    - 客户经理日常监控发现
    - 外部数据变更触发

  3.2 信号推送
    - 实时推送至客户经理PAD端
    - 分级推送（黄色推客户经理，橙色+主管，红色+风险部）

  3.3 核实确认
    - 客户经理在T+1内完成初步核实
    - 区分：真实信号 vs 误报 vs 已化解

  3.4 风险定级
    - 根据核实结果确定风险等级（红/橙/黄）
    - 红色：立即启动应急预案，制定处置方案
    - 橙色：加强监控频率，制定预警化解方案
    - 黄色：跟踪观察，纳入重点监控名单

  3.5 制定处置方案

    红色预警处置方案选项：
    - 宣布贷款提前到期
    - 要求追加担保
    - 冻结未用额度
    - 启动诉讼/仲裁程序
    - 协商债务重组

    橙色预警处置方案选项：
    - 压缩授信额度
    - 提高贷后检查频率
    - 要求企业提供更多信息披露
    - 协商改善方案

  3.6 执行跟踪
    - 风险部定期跟踪处置进展
    - 预警信号未解除前持续监控
    - 处置完成后进行总结评估

四、新一代预警系统的技术实现

  4.1 数据层
    - 实时数据管道对接内外部数据源
    - 数据质量校验和清洗

  4.2 模型层
    - 规则模型：基于专家经验的信号触发规则
    - 统计模型：逻辑回归/决策树的违约预测模型
    - 机器学习模型：XGBoost/LightGBM的违约概率预测
    - 知识图谱：关联风险传导分析

  4.3 应用层
    - 预警看板（大屏）：全行预警情况一目了然
    - 预警工单：自动派发、跟踪、关闭
    - 移动预警：客户经理PAD端实时接收和处理
    - 预警分析：预警命中率、误报率、时效分析

6.4 贷款五级分类
================================================================================

一、五级分类的定义与标准

  五级分类是中国银保监会要求的贷款风险分类体系。

  1.1 正常类
    借款人能按时足额偿还贷款本息，没有任何影响贷款偿还的负面因素。
    
    核心判断：
    - 企业持续经营且盈利
    - 现金流充足
    - 无逾期
    - 无不利信息

  1.2 关注类
    借款人目前有能力偿还贷款，但存在一些可能对偿还产生不利影响的因素。
    
    核心判断：
    - 企业出现经营或财务不利因素
    - 逾期1-90天（含）
    - 借新还旧、展期
    - 他行贷款出现不良
    - 出现预警信号

  1.3 次级类
    借款人还款能力出现明显问题，完全依靠其正常营业收入无法足额偿还贷款，
    即使执行担保也可能造成一定损失。
    
    核心判断：
    - 逾期91-180天（含）
    - 企业出现重大经营困难
    - 担保处置后预计损失 ≤ 30%
    - 重组贷款中确认预期损失较小

  1.4 可疑类
    借款人无法足额偿还贷款本息，即使执行担保也肯定造成较大损失。
    
    核心判断：
    - 逾期181天-360天（含）
    - 企业基本无还款能力
    - 担保处置后预计损失 30%-90%
    - 已进入诉讼程序

  1.5 损失类
    采取所有可能的措施或一切必要的法律程序后，贷款本息仍然无法收回，
    或只能收回极少部分。
    
    核心判断：
    - 逾期 > 360天
    - 企业停产、破产、注销
    - 担保处置后预计损失 > 90%
    - 虽在诉讼但无财产可执行

  五级分类速查表：
  ┌────────┬─────────────┬──────────────────────┐
  │ 分类    │ 逾期天数     │ 核心判断              │
  ├────────┼─────────────┼──────────────────────┤
  │ 正常    │ 无逾期       │ 一切正常              │
  │ 关注    │ 1-90天       │ 有不利因素仍能还款    │
  │ 次级    │ 91-180天     │ 还款能力明显不足      │
  │ 可疑    │ 181-360天    │ 必然产生较大损失      │
  │ 损失    │ > 360天      │ 基本无法收回          │
  └────────┴─────────────┴──────────────────────┘
  
  正常+关注 = 正常贷款
  次级+可疑+损失 = 不良贷款

二、五级分类的操作流程

  2.1 分类频率
    - 对公贷款：至少每季度分类一次
    - 零售贷款：至少每月分类一次
    - 出现重大变化时：即时重分类

  2.2 分类主体
    - 初分：客户经理根据掌握信息初步分类
    - 复审：风险经理复核并提出意见
    - 审定：有权审定人最终确定分类结果
    - 抽查：审计部门定期抽查分类准确性

  2.3 分类方法
  
    对公贷款：
    主要采用"风险矩阵法"——综合考量违约概率和预计损失程度。
    
    零售贷款（笔数多、金额小）：
    主要采用"脱期法"——按逾期天数自动分类。
    - 除非有充分证据证明可以上调分类，否则不得上调

三、五级分类的监管意义

  - 不良贷款率 = 不良贷款余额 / 各项贷款余额
    （银保监会核心监管指标，通常要求 ≤ 5%）

  - 拨备覆盖率 = 贷款减值准备 / 不良贷款余额
    （要求 ≥ 150%）

  - 不良贷款率是银行资产质量的核心指标，直接影响：
    - 市场声誉（股价、融资成本）
    - 监管评级
    - 高管考核

  - 银行有"隐藏不良"的动机
    - 常见手段：借新还旧、展期（掩盖逾期）
    - 银保监会现场检查重点：五级分类准确性

6.5 不良贷款处置与催收
================================================================================

一、催收体系

  1.1 催收阶段

    ┌─────────────────────────────────────────────────────────┐
    │  提醒期（到期前15天 - 逾期1天）                          │
    │    短信提醒、APP推送                                     │
    │    由系统自动发送                                        │
    ├─────────────────────────────────────────────────────────┤
    │  早期催收（逾期1-30天）                                  │
    │    电话催收、短信催收                                    │
    │    客户经理/客服                                          │
    ├─────────────────────────────────────────────────────────┤
    │  中期催收（逾期31-90天）                                 │
    │    电话催收 + 上门催收 + 发送催收函                       │
    │    客户经理 + 催收专员                                    │
    ├─────────────────────────────────────────────────────────┤
    │  后期催收（逾期91天以上）                                │
    │    发送律师函 + 司法催收（诉讼/仲裁）                     │
    │    风险部/法务部 + 外部律师                               │
    ├─────────────────────────────────────────────────────────┤
    │  核销后追索                                              │
    │    持续追索（"账销案存"）                                │
    │    外部催收机构/AMC                                       │
    └─────────────────────────────────────────────────────────┘

  1.2 对公不良处置手段

    a) 现金清收
      - 与企业协商还款计划
      - 分期偿还、利息减免（需审批）

    b) 以物抵债
      - 以非现金资产抵偿债务
      - 须评估价值公允，防止高估
      - 风险：资产贬值、变现困难

    c) 处置抵质押物
      - 协议折价：双方协商定价转让
      - 拍卖变卖：法院拍卖或自主拍卖
      - 流拍后以物抵债

    d) 债务重组
      - 展期、降低利率、部分减免
      - 追加担保
      - 引入战略投资者
      
    e) 诉讼追偿
      - 起诉 → 判决 → 申请执行
      - 时间周期长（6个月-2年+）
      - 难点：企业无财产可执行

    f) 不良资产转让
      批量转让给AMC（资产管理公司）：
      - 2012年：允许批量转让（≥ 3户）
      - 2021年：个贷不良批量转让试点
      - 转让价通常为本金的 20-40%（视资产质量）

    g) 不良资产证券化
      将不良贷款打包为ABS出售：
      - 2016年重启不良资产证券化试点
      - 高优先级获得AAA评级
      - 次级档（通常5-10%）银行自持

    h) 债转股
      - 将债权转为股权
      - 2016年《市场化银行债权转股权指导意见》
      - 银行不得直接将债权转为股权，需通过实施机构（AIC）
      - 五大行均已成立金融资产投资公司（AIC）

  1.3 零售不良处置

    零售贷款单笔金额小、户数多，处置策略不同于对公：

    a) 自催
      银行内部催收团队，覆盖早期逾期

    b) 委外催收
      - 委托第三方催收公司
      - 严监管趋势：禁止暴力催收、规范催收行为
      - 2022年《个人贷款管理办法》进一步约束催收

    c) 司法催收
      - 批量诉讼、线上仲裁
      - 互联网法院支持在线诉讼

    d) 不良资产转让
      - 个人不良贷款批量转让（2021年试点）
      - 信用卡不良ABS

6.6 核销管理
================================================================================

一、核销的定义

  核销是将已经认定无法收回的贷款从银行资产负债表中移除的会计处理。

  核销 = 借：贷款减值准备 / 贷：贷款

  核销的条件：
  - 采取所有可能措施仍无法收回
  - 已认定为损失类
  - 经内部审批和税务认定

二、核销的审批流程

  1. 客户经理提交核销申请（附清收记录、法律文书等证据）
  2. 风险部审核核销条件是否满足
  3. 法律合规部审核法律程序是否穷尽
  4. 有权审批人批准（大额需报董事会）
  5. 税务部门认定损失（企业所得税税前扣除需税务认可）

三、"账销案存"原则

  核销 ≠ 放弃债权！

  - 核销是账务处理，不代表放弃追索权
  - 核销后仍需持续追讨
  - 收回核销贷款计入当期损益（惊喜收入）
  - 建立核销后资产管理台账，专人跟踪

四、核销对银行的影响

  - 消耗贷款减值准备（拨备）
  - 不直接影响当期利润（损失已通过拨备提前确认）
  - 释放资本：核销后风险资产减少，但拨备也相应减少
  - 不良贷款率下降（分子减小）
  - 拨备覆盖率变化：分子(减值准备)分母(不良)同时减少，方向不确定
