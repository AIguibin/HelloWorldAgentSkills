8.2 巴塞尔协议演进（Basel I → II → III → IV）
================================================================================

一、巴塞尔协议I（1988年）

  背景：1980年代拉美债务危机，银行资本普遍不足

  核心内容：
  - 首次提出统一的资本充足率标准：资本/风险加权资产 ≥ 8%
  - 将资产分为5档风险权重（0%、10%、20%、50%、100%）
  - 将资本分为核心资本（Tier 1，≥ 4%）和附属资本（Tier 2）

  局限性：
  - 风险权重过于粗糙（所有企业贷款都是100%）
  - 未考虑信用评级差异、期限差异、风险缓释

二、巴塞尔协议II（2004年）

  三大支柱框架：
  
  第一支柱：最低资本要求
    - 覆盖信用风险、市场风险、操作风险
    - 信用风险：引入标准法和内部评级法（IRB）
      - 标准法：使用外部评级确定风险权重
      - IRB初级法（F-IRB）：银行自建PD模型，LGD/EAD使用监管给定值
      - IRB高级法（A-IRB）：银行自建PD/LGD/EAD全部模型
    - 操作风险：基本指标法、标准法、高级计量法（AMA）

  第二支柱：监督检查
    - 银行内部资本充足评估（ICAAP）
    - 监管机构监督检查（SREP）
    - 要求银行持有超过最低要求的资本（资本缓冲）

  第三支柱：市场纪律
    - 公开信息披露要求
    - 提高透明度，让市场参与监督

三、巴塞尔协议III（2010年发布，逐步实施）

  2008年金融危机的反思：
  - 银行资本质量不够高（核心一级资本过少）
  - 银行杠杆率过高
  - 流动性风险管理严重不足
  - 顺周期效应放大经济波动

  巴塞尔III的核心改革：

  3.1 资本质量提升
    - 核心一级资本充足率：2% → 4.5%
    - 一级资本充足率：4% → 6%
    - 总资本充足率：保持8%
    - 核心一级资本必须是普通股和留存收益

  3.2 资本缓冲体系
    - 资本留存缓冲（CCoB）：核心一级资本的2.5%
    - 逆周期资本缓冲（CCyB）：0-2.5%，由各国决定
    - 系统重要性银行附加资本：1%-3.5%（G-SIBs）
    - 国内系统重要性银行（D-SIBs）附加资本：0.5%-1.5%

  3.3 杠杆率
    - 杠杆率 = 一级资本 / 表内外总暴露 ≥ 3%
    - 作为资本充足率的补充，防止过度杠杆

  3.4 流动性风险管理
    - 流动性覆盖率（LCR）：高流动性资产 / 30天压力情景净现金流出 ≥ 100%
    - 净稳定资金比例（NSFR）：可用稳定资金 / 所需稳定资金 ≥ 100%

  3.5 系统重要性银行
    - 全球系统重要性银行（G-SIBs）：分5个桶级，附加资本1%-3.5%
    - 中国四大行（工农中建）均被认定为G-SIBs

四、巴塞尔协议IV（"Basel III最终方案"，2017年发布）

  主要改进：

  4.1 标准法信用风险改革
    - 细化风险权重层级（从5档扩展到15档+）
    - 对房地产贷款引入LTV分层的风险权重
    - 对无评级企业贷款引入"规模/收入"分层

  4.2 内评法输出下限（Output Floor）
    - 内评法计算的RWA不得低于标准法RWA的72.5%
    - 限制银行通过内部模型过度降低资本要求
    - 分阶段实施：2023年→50%，2025年→55%，2027年→60%...
      最终到72.5%

  4.3 操作风险计量改革
    - 取消高级计量法（AMA）
    - 统一使用标准计量法（SMA）：结合业务规模和损失历史

  4.4 CVA（信用估值调整）框架
    - 调整衍生品交易对手信用风险的计量框架

五、中国实施情况

  中国银行业实施巴塞尔协议总体走在国际前列：
  - 2013年：巴塞尔III在中国落地实施
  - 工农中建交五大行 + 招商银行已获批实施IRB高级法
  - MPA（宏观审慎评估）框架相当于"中国版巴塞尔III补充版"
  - 2024年1月1日起实施《商业银行资本管理办法》（中国版Basel IV）

8.3 资本充足率管理
================================================================================

一、资本的定义

  1.1 核心一级资本（CET1）
    包括：
    - 实收资本/普通股
    - 资本公积
    - 盈余公积
    - 一般风险准备
    - 未分配利润
    - 少数股东资本可计入部分

    扣除项：
    - 商誉
    - 其他无形资产（不含土地使用权）
    - 递延税资产（依赖于未来盈利的部分）
    - 对未并表金融机构的资本投资

  1.2 其他一级资本（AT1）
    - 其他一级资本工具（永续债、优先股）
    - 触发转股/减记条款的资本工具

  1.3 二级资本（Tier 2）
    - 二级资本工具（次级债）
    - 超额贷款损失准备（超过最低拨备要求的部分）

  总资本 = CET1 + AT1 + Tier 2

二、RWA（Risk-Weighted Assets，风险加权资产）计算

  RWA = 信用风险RWA + 市场风险RWA + 操作风险RWA

  信用风险RWA的计算方法：

  方法一：权重法（标准法，全行业适用）

    RWA = ∑(各类资产 × 对应风险权重)
    
    常用风险权重示例：
    - 现金/国债：0%
    - 政策性银行债：0%
    - 一般商业银行债权（3个月内）：20%
    - 一般商业银行债权（3个月以上）：25%
    - 一般企业贷款（投资级）：75%
    - 一般企业贷款：100%
    - 小微企业贷款（500万以下）：75%
    - 个人住房贷款（LTV≤60%）：20%
    - 个人住房贷款（LTV 60-80%）：30%
    - 个人住房贷款（LTV>80%）：50%
    - 信用卡贷款：75%
    - 对未评级企业的股权投资：250%-400%
    - 逾期超过90天的贷款：100%-150%

  方法二：内部评级法（IRB，大中型银行申请）

    见第四章4.2-4.3节的RWA计算公式。

三、资本充足率计算

  核心一级资本充足率 = (CET1 - 扣除项) / RWA
                     ≥ 4.5% + 2.5%(CCoB) + CCyB + 系统重要性附加

  一级资本充足率 = (CET1 + AT1) / RWA
                 ≥ 6% + 2.5%(CCoB) + CCyB + 系统重要性附加

  资本充足率 = 总资本 / RWA
             ≥ 8% + 2.5%(CCoB) + CCyB + 系统重要性附加

  以一家非系统重要性中型银行为例（CCyB取0）：
    核心一级资本充足率 ≥ 4.5% + 2.5% = 7%
    一级资本充足率 ≥ 6% + 2.5% = 8.5%
    资本充足率 ≥ 8% + 2.5% = 10.5%

  以一家G-SIB银行为例（如工商银行，附加1.5%，CCyB取0.5%）：
    核心一级资本充足率 ≥ 4.5% + 2.5% + 0.5% + 1.5% = 9%
    一级资本充足率 ≥ 6% + 2.5% + 0.5% + 1.5% = 10.5%
    资本充足率 ≥ 8% + 2.5% + 0.5% + 1.5% = 12.5%

8.4 大额风险暴露管理
================================================================================

一、监管框架

  依据：《商业银行大额风险暴露管理办法》（银保监会2018年第1号令）

二、核心定义

  风险暴露：银行承担的信用风险敞口，包括表内资产、表外承诺和交易对手信用风险。

  大额风险暴露：单一客户/关联集团风险暴露超过银行一级资本净额的一定比例。

三、监管限额

  单一客户风险暴露 ≤ 一级资本净额 × 15%
  关联集团风险暴露 ≤ 一级资本净额 × 20%（2023年过渡期结束后的标准）
  同业客户风险暴露 ≤ 一级资本净额 × 25%（3个月以内）或 15%（3个月以上）
  全球系统重要性银行之间的同业暴露 ≤ 一级资本净额 × 15%

  注意：这是比巴塞尔更严格的要求。
  巴塞尔：单一客户 ≤ 合格资本的25%
  中国：单一客户 ≤ 一级资本净额的15%

四、客户识别

  "单一客户"不仅指法律实体，还包括经济关联：

  - 股权关联（持股 > 50% 或实际控制）
  - 协议安排（VIE、一致行动人）
  - 人事实质性关联（关键管理人员交叉）
  - 资金往来实质性依赖（销售/采购占比过高）

  关联客户需合并计算风险暴露。

五、豁免

  以下可豁免或减计：
  - 以国债/央票/政策性银行债质押的贷款（减计质押金额对应部分）
  - 以现金/存单质押的贷款（减计质押部分）
  - 特定政策性业务

六、新一代系统的实现

  - 实时计算大额暴露（大额业务审批时即时校验）
  - 集团关联关系自动识别合并
  - 接近限额预警
  - 超限额硬拦截
  - 大额暴露报表自动生成

8.5 关联交易管理
================================================================================

一、监管依据

  《商业银行关联交易管理办法》（银保监会2021年第1号令）

二、关联方定义

  2.1 法人关联方
    - 持有银行5%以上股份的法人
    - 银行控股股东及同一控制下的关联企业
    - 银行控制的子公司
    - 银行董事、监事、高管控制的企业

  2.2 自然人关联方
    - 银行董事、监事、高管
    - 持有银行5%以上股份的自然人
    - 银行主要股东的董事、监事、高管
    - 上述人员的近亲属（配偶、父母、子女等）

三、关联交易类型

  - 授信类关联交易：向关联方提供贷款、承兑、保函、信用证等
  - 资产转移类：购买/出售关联方资产
  - 服务类：向关联方提供或接受服务
  - 存款类：关联方存款
  - 其他类

四、监管红线

  4.1 总量控制
    银行对一个关联方的授信余额 ≤ 资本净额的 10%
    银行对一个集团关联方的授信余额 ≤ 资本净额的 15%
    银行对全部关联方的授信余额 ≤ 资本净额的 50%

  4.2 交易条件
    - 关联交易价格不得优于非关联方的可比交易价格
    - 不得为关联方提供无担保融资（特殊情况例外）
    - 不得接受银行自身股权作为质押

  4.3 审批要求
    - 重大关联交易需董事会下设关联交易控制委员会审批
    - 关联董事需回避表决
    - 一般关联交易按内部权限审批，但需定期向委员会报备

五、新一代系统的关联交易管理

  - 关联方名单统一管理（自动识别、定期更新）
  - 关联交易全流程标记（业务发起时自动识别、特殊流程流转）
  - 限额实时监控
  - 关联交易台账与报表自动生成
  - 重大关联交易披露公告自动生成

8.6 流动性风险管理
================================================================================

一、流动性风险概述

  流动性风险是指银行虽有清偿能力，但无法及时获得充足资金或以合理成本
  获得资金以应对资产增长或支付到期债务的风险。

  银行的天然流动性错配：短借长贷
  - 负债端：存款以活期和短期为主
  - 资产端：贷款以中长期为主
  - 但银行必须随时满足储户提款需求

二、关键监管指标

  2.1 流动性覆盖率（LCR）

    LCR = 合格高流动性资产（HQLA）/ 未来30天压力情景下的净现金流出 ≥ 100%

    HQLA包括：
    - 一级资产（无折价）：现金、央行准备金、国债
    - 二级资产（15%折价）：AA-以上公司债、A-至A+公司债（50%折价）

    现金流出假设（压力情景）：
    - 零售存款流失率：3%-10%
    - 企业存款流失率：20%-40%
    - 同业存款流失率：100%
    - 已承诺但未提用的贷款额度提取率：10%-30%
    - 或有融资义务：按CCF计算

  2.2 净稳定资金比例（NSFR）

    NSFR = 可用稳定资金（ASF）/ 所需稳定资金（RSF） ≥ 100%

    ASF：按稳定性对负债和权益分配不同因子
    - 资本：100%
    - 零售活期存款：90%
    - 中小企业存款：85%-90%
    - 企业活期存款：50%
    - 同业短期拆借：0%

    RSF：按流动性对资产分配不同因子
    - 现金：0%
    - 存放同业（短期）：15%
    - 住房按揭贷款（LTV低）：50%-65%
    - 企业贷款：65%-85%
    - 固定资产：100%

  2.3 其他流动性指标
    - 流动性比例 ≥ 25%
    - 核心负债依存度 ≥ 60%
    - 流动性缺口率 ≥ -10%
    - 存贷比（监测指标，非硬性约束）

三、流动性风险管理体系

  1. 流动性风险偏好与限额体系
    - 董事会设定风险偏好（风险容忍度）
    - 管理层分解为内部限额（如：日间流动性缺口上限）

  2. 流动性风险计量
    - 现金流缺口分析（按期限桶：隔夜、7天、1月、3月、6月、1年...）
    - 压力测试（机构特定、市场整体、混合场景）
    - 应急融资计划（CFP）

  3. 优质流动性资产储备
    - 保持足够的无负担高流动性资产
    - 分散化（不同币种、不同市场）

  4. 日间流动性管理
    - 实时监测清算账户余额
    - 大额支付系统流动性管理

================================================================================
8.7 宏观审慎评估（MPA）
================================================================================

一、MPA概述

  MPA（Macro Prudential Assessment）是人民银行于2016年推出的宏观审慎
  评估体系，被称为"中国版宏观审慎政策框架"。

  核心目标：防范系统性金融风险，逆周期调节信贷增长。

  评估对象：所有商业银行（含国有大行、股份制、城商行、农商行等）

  评估频率：每季度一次

二、MPA七大类指标

  ┌──────────────┬────────────────────────────────┐
  │ 评估维度      │ 核心指标                        │
  ├──────────────┼────────────────────────────────┤
  │ 资本和杠杆     │ 资本充足率（宏观审慎资本充足率）│
  │              │ 杠杆率                          │
  ├──────────────┼────────────────────────────────┤
  │ 资产负债      │ 广义信贷增速（与GDP+CPI匹配）    │
  │              │ 同业负债占比                     │
  ├──────────────┼────────────────────────────────┤
  │ 流动性        │ LCR、NSFR                      │
  │              │ 流动性比例                      │
  ├──────────────┼────────────────────────────────┤
  │ 定价行为      │ 利率定价自律机制执行情况          │
  │              │ 存款利率是否突破自律上限          │
  ├──────────────┼────────────────────────────────┤
  │ 资产质量      │ 不良贷款率                      │
  │              │ 拨备覆盖率                      │
  ├──────────────┼────────────────────────────────┤
  │ 跨境融资      │ 跨境融资风险加权余额             │
  ├──────────────┼────────────────────────────────┤
  │ 信贷政策执行  │ 普惠金融贷款占比                 │
  │              │ 绿色信贷占比                    │
  │              │ 涉农贷款占比                    │
  └──────────────┴────────────────────────────────┘

三、MPA评分与奖惩

  每项指标分三档：
  - 优秀（A档，90分+）：执行优于要求，给予奖励
  - 合规（B档，60-89分）：满足要求
  - 不达标（C档，< 60分）：实施惩罚

  奖励与惩罚措施：
  - A档：法定准备金利率上浮10%-30%
  - C档：法定准备金利率下浮10%-30%
  - C档连续两季：可能取消MLF/SLF等货币政策工具资格
  - C档严重者：约谈高管、限制业务准入

四、广义信贷增速约束

  MPA的核心创新在于"广义信贷增速"指标：

  广义信贷增速偏离度 = 实际广义信贷增速 - M2目标增速 - CPI目标 - 容忍度

  广义信贷 = 各项贷款 + 债券投资 + 股权及其他投资 + 买入返售 + 存放/拆放同业

  这改变了传统的"合意贷款规模"管理模式，更全面覆盖银行的信用扩张活动。

8.8 绿色信贷与ESG
================================================================================

一、绿色信贷政策背景

  - 2020年：中国提出"双碳"目标（碳达峰2030、碳中和2060）
  - 2021年：人民银行发布《银行业金融机构绿色金融评价方案》
  - 2022年：银保监会发布《银行业保险业绿色金融指引》

二、绿色信贷核心要求

  2.1 产业方向
    鼓励投向：
    - 节能环保产业
    - 清洁能源（风电、光伏、水电、核电）
    - 新能源汽车
    - 绿色建筑
    - 碳减排技术

    限制投向（"两高一剩"）：
    - 钢铁、水泥、电解铝、平板玻璃、船舶等产能过剩行业
    - 火电、煤炭、石化等高排放行业（需"转型金融"）

  2.2 考核要求
    监管对银行绿色信贷的考核维度：
    - 绿色信贷占比及增速
    - 绿色信贷不良率
    - 环境信息披露质量
    - 绿色金融制度建设

  2.3 风险管理
    - 将环境与社会风险纳入信贷全流程管理
    - 客户环境信用评价（环保黑名单一票否决）
    - 贷前环境与社会风险评估（ESG尽职调查）
    - 贷后环境风险动态监测

三、ESG在信贷管理中的应用

  ESG = Environment（环境）+ Social（社会）+ Governance（治理）

  ESG在客户评级中的应用：
  - 环境维度：碳排放、排污、绿色认证
  - 社会维度：劳动权益、安全生产、社区关系
  - 治理维度：公司治理结构、信息披露、商业道德

  ESG评分影响：
  - 客户准入（ESG低分客户限制准入）
  - 贷款利率（ESG高分客户享受绿色优惠利率）
  - 贷款额度（ESG表现纳入额度调整因子）

  1.1 1104报表体系（银保监会非现场监管报表）

    - G4A 合格资本情况表
    - G4B 风险加权资产计算表
    - G25 流动性覆盖率情况表
    - G26 净稳定资金比例情况表
    - S序列 特色报表

  1.2 金融统计报表（人民银行）
    - 存贷款统计（月报/旬报）
    - 社会融资规模统计
    - 信贷投向统计

  1.3 征信报送
    - 企业征信：每月报送贷款、还款信息
    - 个人征信：每日/每月报送

  1.4 反洗钱报送
    - 大额交易报告
    - 可疑交易报告
