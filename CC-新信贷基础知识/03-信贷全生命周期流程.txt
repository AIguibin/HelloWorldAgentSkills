3.1 信贷全生命周期总览
================================================================================

一、整体流程图

  客户营销触达
      ↓
  ┌─────────────────────────────────────────────┐
  │               贷前阶段                       │
  │  客户准入 → 尽职调查 → 反洗钱筛查           │
  └─────────────────────────────────────────────┘
      ↓
  ┌─────────────────────────────────────────────┐
  │               贷中阶段                       │
  │  信用评级 → 统一授信 → 业务审批 → 签约放款   │
  └─────────────────────────────────────────────┘
      ↓
  ┌─────────────────────────────────────────────┐
  │               贷后阶段                       │
  │  贷后监控 → 风险预警 → 到期回收             │
  │       ↓（逾期）                              │
  │  催收 → 诉讼/仲裁 → 核销                    │
  └─────────────────────────────────────────────┘

二、关键角色与职责

  前台（业务部门 / 客户经理）
    - 客户营销与关系维护
    - 贷前尽职调查
    - 贷后日常监控（第一道防线）
    - 风险预警核实
    - 逾期催收

  中台（风险管理部 / 授信审批部）
    - 信贷政策制定
    - 评级审核与确认
    - 授信方案审批
    - 业务审批（独立审批人制度）
    - 风险模型开发与验证
    - 风险报告

  后台（放款中心 / 运营管理部）
    - 放款条件审核
    - 合同管理
    - 抵质押登记办理
    - 档案管理
    - 账务处理

  三道防线体系：
    第一道防线：业务部门（前台）—— 日常识别与管理风险
    第二道防线：风险管理部门（中台）—— 独立监控与评估风险
    第三道防线：审计部门 —— 独立审计与评价

3.2 贷前阶段：客户准入与尽职调查
================================================================================

一、客户准入

  1.1 准入标准（白名单 / 黑名单）
    - 行业准入：符合国家产业政策，不属于"两高一剩"限制行业
    - 地域准入：在银行服务范围内
    - 资信准入：无重大不良信用记录
    - 关联关系核查：识别实际控制人、集团关联关系
    - 反洗钱（AML）：客户身份识别、受益所有人穿透、制裁名单筛查

  1.2 禁止准入情形
    - 列入失信被执行人名单
    - 列入反洗钱制裁名单
    - 环保黑名单企业
    - 涉及非法集资、非法经营
    - 贷款用于禁止性领域（如股市、房市投机）

二、尽职调查（Due Diligence）

  2.1 对公客户尽职调查要点

    a) 主体资格调查
      - 营业执照核查（国家企业信用信息公示系统）
      - 经营资质（特殊行业许可证）
      - 公司章程、股权结构
      - 实际控制人穿透

    b) 经营状况调查
      - 经营历史与行业地位
      - 上下游客户稳定性
      - 产销状况（产能利用率、产销率）
      - 核心竞争力（技术、品牌、渠道）

    c) 财务状况分析（核心！）
      - 资产负债表：资产质量（应收/存货/固定资产）、负债结构
      - 利润表：收入真实性、盈利持续性、费用合理性
      - 现金流量表：经营/投资/筹资现金流分析
      - 财务比率：偿债能力、营运能力、盈利能力、成长能力

      关键财务比率速查：
      ┌──────────────────┬─────────────────────────────┐
      │  类别             │  关键指标                    │
      ├──────────────────┼─────────────────────────────┤
      │  偿债能力         │  资产负债率、流动比率、       │
      │                   │  速动比率、利息保障倍数       │
      ├──────────────────┼─────────────────────────────┤
      │  营运能力         │  应收账款周转率、存货周转率、  │
      │                   │  总资产周转率                 │
      ├──────────────────┼─────────────────────────────┤
      │  盈利能力         │  毛利率、净利率、ROA、ROE     │
      ├──────────────────┼─────────────────────────────┤
      │  成长能力         │  收入增长率、净利润增长率      │
      └──────────────────┴─────────────────────────────┘

    d) 信用状况调查
      - 人民银行征信报告查询
      - 法院被执行人信息查询
      - 税务信用等级查询
      - 行业口碑与商誉调查

    e) 贷款用途与还款来源调查
      - 用途真实性核实（合同、发票、立项文件）
      - 第一还款来源：经营活动现金流
      - 第二还款来源：担保措施变现

    f) 担保调查
      - 担保人的担保资格与担保能力
      - 抵质押物权属、价值、可变现性
      - 评估报告审查（外部评估 + 内部认定）

  2.2 零售客户尽职调查要点

    - 身份核实（身份证、人脸识别）
    - 收入核实（工资流水、纳税证明、社保公积金）
    - 征信查询（个人征信报告）
    - 负债情况（现有贷款、信用卡使用率）
    - 用途核实（购房合同、消费凭证）
    - 反欺诈筛查（多头借贷、团伙欺诈识别）

三、新一代系统的尽职调查数字化

  - 企业征信报告自动解析
  - 财务报表OCR识别 + 自动勾稽校验
  - 外部数据实时接口：工商变更、司法涉诉、税务信息、海关进出口
  - 关联关系图谱自动生成
  - 尽调报告模板化 + 关键信息自动填充
  - AI辅助：财务异常检测、行业对标分析

3.3 贷中阶段一：信用评级
================================================================================

信用评级是后续授信、审批、定价的基础，是整个信贷决策链条的起点。
（详见第四章 4.1 节）

简要流程：
  评级模型选择 → 定量评价（财务指标打分） → 定性评价（管理能力、行业地位等）
    → 特例调整 → 评级推翻（如需） → 评级审定 → 确定PD（违约概率）

3.4 贷中阶段二：统一授信
================================================================================

一、统一授信的基本概念

  统一授信是银行对单一客户（含关联集团）统一核定最高风险承受额度，
  该客户在银行的所有信用风险敞口（表内+表外）合计不得超过该额度。

  基本原则：
    1. 先评级、后授信、再用信
    2. 所有信用风险敞口纳入统一授信管理
    3. 集团客户合并计算，关联交易不放大集团授信
    4. 余额控制、动态调整

二、授信方案要素

  一个完整的授信方案包含：
    - 授信总额度
    - 授信期限
    - 产品切分：流动资金贷款额度 / 银承额度 / 信用证额度 / 保函额度等
    - 担保要求：担保方式、抵质押率、担保人
    - 定价条件：利率底线、费用
    - 约束性条件：财务指标维持承诺、后续监管要求
    - 授信审批层级

三、额度测算模型

  3.1 对公客户额度测算

    营运资金需求量 = 上年度销售收入 × (1 + 预计增长率) 
                      × (应收账款周转天数 + 存货周转天数 - 应付账款周转天数) / 360

    授信额度上限 = min(营运资金需求量, 净资产 × 倍数, 行业限额)
    
    其中倍数一般 ≤ 1.0（即贷款不超过净资产）

  3.2 零售客户额度测算

    个人住房贷款额度 = 房价 × (1 - 首付比例)
                      ≤ 月收入 × 还款倍数 × (1 - 现有负债/收入比)

    信用卡额度 = f(收入水平, 信用评分, 人行征信记录)
               通常 = 月收入的2-5倍

四、集团客户统一授信

  集团客户识别：
    - 股权关联：持股 > 50% 或实际控制
    - 协议控制：VIE架构、一致行动人
    - 人事控制：关键管理人员重叠
    - 家族关联：家族成员实际控制多个企业

  集团授信管理：
    - 集团授信总额 ≤ 银行净资本的15%（监管红线）
    - 集团内各成员企业授信之和 ≤ 集团授信总额
    - 成员企业间可调剂但需严格审批

3.5 贷中阶段三：业务审批
================================================================================

一、审批体制

  1.1 审批模式
    a) 独立审批人制度（主流）
      - 设立专职审批人，独立于业务条线
      - 审批人按权限分级：初级、中级、高级审批人
      - 审批人对自己审批的贷款质量负责（不良率纳入绩效考核）

    b) 贷审会制度
      - 大额/复杂/争议案件提交贷审会集体决策
      - 委员一人一票，多数决
      - 行长有一票否决权，但不能一票通过权

    c) 双人审批制
      - 两人共同审批，互相制衡

  1.2 审批权限
    按维度设定权限：
    - 单笔金额上限
    - 产品类型限制
    - 行业限制
    - 客户信用等级要求

二、审批流程

  客户经理发起 → 支行/分部初审 → 有权审批人审批 → 签批
      ↓（超权限）
    上级行审批
      ↓（超大额）
    总行审批

  新一代系统的流程特征：
    - 电子化全流程，无纸化审批
    - 通过规则引擎自动校验合规条件
    - 低风险业务自动审批（如国债质押贷款、存单质押贷款）
    - 审批轨迹全程留痕，不可篡改

三、审批决策要点

  1. 贷不贷？
    - 客户是否符合准入条件
    - 信用评级是否达到底线要求
    - 贷款用途是否合规合理

  2. 贷多少？
    - 额度测算是否合理
    - 是否超过客户偿债能力
    - 是否超过限额管理要求

  3. 怎么贷？
    - 期限是否匹配（短贷短用、长贷长用）
    - 利率定价是否覆盖风险
    - 还款计划是否合理

  4. 怎么保？
    - 担保措施是否充足
    - 抵质押物价值是否公允
    - 担保人是否有代偿能力

  5. 怎么管？
    - 贷后管理要求是否明确
    - 约束性条件是否到位

四、审批结论

  - 同意：按申请方案批准
  - 有条件同意：附加额外条件（如增加担保、提高利率）
  - 削减：削减额度或缩短期限
  - 否决：不同意授信

3.6 贷中阶段四：签约放款
================================================================================

一、签约环节

  1.1 合同管理
    - 合同要素完整性校验（主体、金额、利率、期限、担保、违约条款）
    - 合同模板标准化 + 个性化条款
    - 电子合同 + CA数字签名（新一代趋势）
    - 合同版本管理与合规审查

  1.2 面签核保
    - 双人面签（客户经理 + 风险经理）
    - 核保：核实担保人意愿真实性
    - 拍照/录像留证
    - 反欺诈核查（人脸识别+活体检测）

二、放款条件落实

  放款中心（后台独立岗位）审核以下条件：

  2.1 先决条件
    a) 审批条件落实
      - 所有审批批复中的前提条件是否满足
      - 约束性条款是否写入合同
    
    b) 担保条件落实
      - 抵质押合同签署
      - 抵质押登记办理（不动产登记、动产融资统一登记公示系统）
      - 保证合同签署
      - 抵质押物权属证明及他项权证收妥

    c) 法律合规条件
      - 借款主体有权机构决议（董事会/股东会决议）
      - 法定代表人/授权代理人身份核实
      - 法律意见书（如需）

  2.2 放款审核关卡
    放款审核 → 复核 → 有权签批人批准 → 资金划转

  2.3 受托支付 vs 自主支付
  
    受托支付（主流）：
      - 贷款资金由银行直接支付给借款人的交易对手
      - 超过一定金额（对公通常500万+）必须受托支付
      - 防范资金挪用

    自主支付：
      - 小额贷款（通常50万以下）
      - 借款人自行支付，事后提供支付凭证

三、账务处理

  贷款发放：
    借：客户贷款账户（资产科目）  XXX元
    贷：客户存款账户              XXX元

  利息计提：
    借：应收利息          YYY元
    贷：利息收入          YYY元

  按期还款：
    借：客户存款账户      ZZZ元
    贷：客户贷款账户      本金部分
        利息收入          利息部分

3.7 贷后阶段：监控、预警、回收与处置
================================================================================

（详见第六章完整展开，此处概述整体框架）

一、贷后监控

  1.1 日常监控
    - 贷款资金流向监控
    - 企业经营状况跟踪
    - 财务数据定期收集与分析
    - 征信变化监控

  1.2 定期检查
    - 首次跟踪检查（放款后30日内）
    - 日常检查（每季度不少于一次）
    - 重点检查（出现风险信号时增加频率）

  1.3 专项检查
    - 行业风险排查
    - 区域风险排查
    - 特定产品风险排查

二、风险预警

  - 风险信号识别（财务恶化、经营异常、管理变动、负面舆情）
  - 预警信号分级（红色/橙色/黄色）
  - 预警核查与处置

三、到期回收

  - 到期前提醒
  - 正常还款处理
  - 展期（需审批，有次数限制）
  - 借新还旧（严格管控，需满足特定条件）
  - 无还本续贷（小微企业，银监发〔2014〕36号）

四、逾期处置

  - 逾期90天以上必须划入不良贷款
  - 催收管理（短信 → 电话 → 上门 → 律师函）
  - 诉讼/仲裁
  - 处置抵质押物
  - 核销：符合条件的不良贷款从资产负债表移除
  - 账销案存：核销后继续追索

3.8 新一代系统的流程再造
================================================================================

一、传统流程痛点

  1. 流程割裂
    - 评级、授信、审批各系统独立，数据不互通
    - 客户重复提交材料，体验差

  2. 人工依赖度高
    - 尽调报告手工撰写
    - 审批决策依赖个人经验
    - 放款审核逐笔人工核对

  3. 时效差
    - 大额对公贷款从申请到放款可能耗时1-3个月
    - 无法满足小微企业"短、频、快"的融资需求

  4. 贷后管理薄弱
    - 重贷轻管，贷后检查流于形式
    - 风险信号识别滞后，反应被动

二、新一代流程再造方向

  1. 端到端线上化
    - 客户门户：在线申请、上传资料、查询进度
    - 移动展业：客户经理Pad端完成尽调、面签
    - 审批移动A随时随地进行审批
    - 电子合同 + 电子签章

  2. 智能决策
    - 规则引擎自动化审批（低风险标准化产品）
    - AI辅助审批（高风险复杂产品的审批建议）
    - 自动化贷后预警（机器学习识别风险模式）

  3. 流程并行化
    - 评级、授信、业务审批可并行推进（而非严格串行）
    - 部门间信息共享减少重复工作

  4. 数据驱动
    - 尽调报告自动生成
    - 财务报表智能分析
    - 关联关系图谱自动构建
    - 外部数据实时同步

  5. 全流程风控嵌入
    - 每个环节都有风控检查点
    - 风险信号实时推送
    - 红线规则硬控制（超限、超权限自动拦截）

================================================================================

- 贷后监控/预警 - 到期回收/逾期处置"的全生命周期流程。重点阐述了各阶段的核心工作
内容、关键决策点、岗位职责和三道防线体系。同时指出传统流程的痛点（流程割裂、人工
依赖、时效差、贷后薄弱），以及新一代信贷系统"端到端线上化、智能决策、流程并行化、
数据驱动、全流程风控嵌入"的再造方向。
