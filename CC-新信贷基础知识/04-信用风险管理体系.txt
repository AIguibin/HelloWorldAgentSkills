4.1 信用评级体系
================================================================================

信用评级是银行信用风险管理的基石，所有后续风险计量和管理均基于评级结果。

一、评级的本质

  评级是对借款人未来一段时间内（通常1年）违约可能性的排序和量化。
  
  两类评级：
  - 借款人评级（Obligor Rating）：评估借款主体本身的信用状况
  - 债项评级（Facility Rating）：评估具体贷款业务的损失程度（考虑担保等缓释后）

二、评级主标尺（Master Scale）

  银行内部建立统一的主标尺，将客户分为若干信用等级，每级对应一个PD值。

  典型的主标尺示例（国内大型银行）：
  ┌──────────┬──────────┬───────────┬────────────────┐
  │ 信用等级  │ 含义      │ PD区间     │ 对标外部评级    │
  ├──────────┼──────────┼───────────┼────────────────┤
  │ AAA      │ 极佳      │ ≤ 0.05%   │ AAA/AA+        │
  │ AA+      │ 优秀      │ 0.05-0.1% │ AA              │
  │ AA       │ 优秀      │ 0.1-0.2%  │ AA-             │
  │ A+       │ 良好      │ 0.2-0.4%  │ A+              │
  │ A        │ 良好      │ 0.4-0.7%  │ A               │
  │ BBB+     │ 较好      │ 0.7-1.2%  │ BBB+/BBB        │
  │ BBB      │ 较好      │ 1.2-2.0%  │ BBB-            │
  │ BB       │ 一般      │ 2.0-4.0%  │ BB              │
  │ B        │ 可接受    │ 4.0-8.0%  │ B               │
  │ CCC      │ 关注      │ 8.0-15%   │ CCC             │
  │ CC       │ 预警      │ 15-30%    │ CC              │
  │ C        │ 危险      │ 30-50%    │ C               │
  │ D        │ 违约      │ 100%      │ D               │
  └──────────┴──────────┴───────────┴────────────────┘

  通常BBB及以上为投资级（Investment Grade），BB及以下为投机级。

三、对公客户评级模型

  对公客户评级 = 定量评价 + 定性评价 + 特例调整

  3.1 定量评价（财务指标打分，占权重约60-70%）

    将企业财务报表数据输入模型，自动计算得分：
    
    a) 规模指标
      - 总资产、净资产、营业收入
      - 规模越大，抗风险能力越强，得分越高

    b) 偿债能力（核心）
      - 资产负债率 = 总负债 / 总资产
      - 流动比率 = 流动资产 / 流动负债
      - 速动比率 = (流动资产 - 存货) / 流动负债
      - 利息保障倍数 = EBIT / 利息支出
      - 现金债务保障倍数 = 经营性现金流 / 总债务

    c) 盈利能力
      - ROE = 净利润 / 净资产
      - ROA = 净利润 / 总资产
      - 营业利润率 = 营业利润 / 营业收入
      - 毛利率 = (收入 - 成本) / 收入

    d) 营运能力
      - 应收账款周转率 = 营业收入 / 应收账款平均余额
      - 存货周转率 = 营业成本 / 存货平均余额
      - 总资产周转率 = 营业收入 / 总资产平均余额

    e) 成长能力
      - 营业收入增长率
      - 净利润增长率
      - 总资产增长率

  3.2 定性评价（非财务因素打分，占权重约30-40%）

    a) 经营管理
      - 管理层从业经验与业绩
      - 公司治理结构完善程度
      - 战略规划清晰度与可行性
      - 财务管理制度规范性

    b) 行业与竞争
      - 行业景气度与发展前景
      - 市场占有率与竞争地位
      - 技术/品牌/渠道壁垒
      - 上下游议价能力

    c) 信用记录
      - 银行信用记录（还款情况、逾期历史）
      - 商业信用记录（应付账款支付情况）
      - 税务合规记录
      - 司法诉讼记录

    d) 银企关系
      - 与本行合作年限
      - 存款与结算业务贡献度
      - 历史授信使用率

  3.3 特例调整

    以下情况触发评级降级：
    - 财务造假或信息不实
    - 重大负面舆情
    - 列为失信被执行人
    - 实际控制人涉刑
    - 被出具非标审计意见

四、零售客户评分卡

  零售客户数量巨大，无法逐户尽调，采用评分卡（Scorecard）模式。

  4.1 申请评分卡（Application Scorecard）
    在客户申请贷款时使用，评估新客户的信用风险。
    
    典型变量：
    - 年龄、婚姻状况、学历
    - 职业、工作年限、单位性质
    - 收入水平、房贷/收入比
    - 资产状况（房产、车产）
    - 人行征信：贷款记录、信用卡使用率、查询次数、逾期记录
    - 行为数据（如有）：电商消费、社交关系

  4.2 行为评分卡（Behavioral Scorecard）
    针对存量客户，动态评估还款能力和意愿。
    
    典型变量（比申请评分卡更丰富）：
    - 还款行为：是否准时、提前/滞后天数趋势
    - 额度使用率
    - 账户余额变化
    - 交易行为异常检测
    - 与本行其他产品交互行为

  4.3 催收评分卡（Collection Scorecard）
    针对逾期客户，评估收回欠款的可能性和策略。
    
    - 逾期天数及金额
    - 还款态度和历史
    - 联系方式有效性和响应度
    - 资产状况和可执行性

五、评级管理与治理

  5.1 评级推翻（Rating Override）
    系统自动计算出的评级，经审批后可向上或向下推翻。
    需有充分理由支撑，推翻比例通常限制在5%-10%以内。

  5.2 评级更新
    - 对公客户至少每年重评一次
    - 出现重大变化时即时重评
    - 零售客户评分卡实时或按月更新

  5.3 评级验证
    - 返回检验（Back-testing）：PD预测值 vs 实际违约率
    - 区分力检验：AR（Accuracy Ratio）/ Gini系数 / KS值
    - 稳定性检验：PSI（Population Stability Index）

================================================================================
4.2 违约概率（PD）模型
================================================================================

一、违约概率的定义

  PD（Probability of Default）是借款人在未来12个月内发生违约的概率。

二、违约的认定标准（巴塞尔协议定义）

  出现以下任一情况即认定"违约"：
  
  1. 银行认定，除非采取追索措施（如变现担保品），借款人可能无法全额偿还债务
  
  2. 债务人对银行集团债务的任何信贷债务逾期超过90天

  3. 债务人发生以下"不良"认定：
    - 贷款五级分类为次级、可疑或损失
    - 已进行核销或计提专项减值
    - 银行被迫出售信贷资产且产生重大损失
    - 同意对债务进行"困境债务重组"（包括展期、减免）
    - 债务人已申请破产或进入破产保护程序

三、PD的计算方法

  3.1 内部评级法（IRB）下的PD

    对于有足够数据积累的银行，可采用内部模型计算PD：

    PD = f(评级结果) 

    校准方法：
    - 长期平均违约率法：取该评级等级3-5年平均违约率
    - 映射法：将内部评级映射到外部评级或行业基准PD
    - 统计模型：Logistic回归、决策树、机器学习模型

  3.2 标准法下的风险权重

    对非内评法银行，直接使用外部评级映射风险权重：
    
    外部评级（标普）   风险权重
    AAA to AA-          20%
    A+ to A-             50%
    BBB+ to BBB-        100%
    BB+ to B-           100%
    Below B-            150%
    Unrated             100%

四、PD模型的校验与监控

  4.1 区分力指标
    - AR（Accuracy Ratio）= 2×AUC - 1，越高越好，通常 > 0.4视为可用
    - KS（Kolmogorov-Smirnov）= max|好客户累计% - 坏客户累计%|
      - KS > 0.3：良好
      - KS > 0.4：优秀
      - KS > 0.5：非常好（但需警惕过拟合）

  4.2 校准指标
    - Brier Score：预测概率与实际结果的均方误差
    - Binomial Test：检验PD预测值与实际违约率是否一致

  4.3 稳定性指标
    - PSI（Population Stability Index）< 0.1：模型稳定
    - PSI 0.1-0.25：需要关注
    - PSI > 0.25：模型显著变化，需重新开发

4.3 违约损失率（LGD）与违约风险暴露（EAD）
================================================================================

一、LGD（Loss Given Default，违约损失率）

  1.1 定义
    LGD是债务人违约后，银行实际损失占风险暴露的比例。
    LGD = 1 - 回收率（Recovery Rate）

  1.2 影响LGD的关键因素

    a) 担保方式（最核心因素）
      不同类型担保的典型LGD：
      ┌─────────────────────┬──────────────────┐
      │ 担保类型             │ 典型LGD           │
      ├─────────────────────┼──────────────────┤
      │ 现金/存款质押        │ 0%               │
      │ 国债/金融债质押      │ 0-5%             │
      │ 房产抵押（住宅）     │ 20-35%           │
      │ 房产抵押（商业）     │ 30-45%           │
      │ 土地使用权抵押       │ 35-50%           │
      │ 机器设备抵押         │ 40-60%           │
      │ 存货质押             │ 50-70%           │
      │ 应收账款质押         │ 30-60%           │
      │ 第三方保证           │ 20-45%（视保证人）│
      │ 信用（无担保）       │ 45-75%           │
      └─────────────────────┴──────────────────┘

    b) 经济周期
      - 经济下行时，抵质押物贬值 + 处置困难 → LGD上升
      - 巴塞尔要求使用"经济衰退期LGD"（Downturn LGD）

    c) 行业特征
      - 资产密集型行业（制造业、房地产）：抵质押物充足 → LGD较低
      - 轻资产行业（科技、服务）：抵质押物少 → LGD较高

    d) 违约时点
      - 违约前越早回收，LGD越低
      - 长期拖延导致贷款积欠利息，加大损失

    e) 处置效率
      - 法律环境、司法效率
      - 银行催收能力

二、EAD（Exposure at Default，违约风险暴露）

  2.1 定义
    债务人违约时银行面临的全部风险敞口。
    
  2.2 不同产品的EAD
    a) 定期贷款：EAD = 当前贷款余额（已提用部分）
    
    b) 循环额度/承诺贷款：
       EAD = 已提用金额 + CCF × 未提用金额
       其中CCF（Credit Conversion Factor，信用转换系数）：
       - 可无条件撤销的承诺：CCF = 0%
       - 不可撤销的短期承诺（≤ 1年）：CCF = 20%
       - 不可撤销的长期承诺（> 1年）：CCF = 50%
    
    c) 表外产品：
       - 银行承兑汇票：CCF = 100%
       - 信用证、保函（贸易相关）：CCF = 20%-50%
       - 融资性保函：CCF = 100%

三、内部评级法（IRB）下的风险加权资产（RWA）计算

  对于公司风险暴露（IRB初级法）：
  
  RWA = K × 12.5 × EAD
  
  其中 K 是资本要求函数：
  K = LGD × [N((1-R)^(-0.5) × G(PD) + (R/(1-R))^0.5 × G(0.999)) - PD] 
      × (1 + (M-2.5) × b(PD)) / (1 - 1.5 × b(PD))
  
  参数说明：
  - N(x): 标准正态分布的累积分布函数
  - G(x): N(x)的反函数
  - R: 资产相关性（由巴塞尔给定公式）
  - M: 有效期限
  - b(PD): 期限调整系数

  这个公式看起来很复杂，但核心思想是：
  - PD越高 → K越大
  - LGD越高 → K越大  
  - 期限越长 → K越大
  - 对于高质量（PD低）的借款人，期限调整带来的资本增幅更大

4.4 风险缓释体系
================================================================================

一、风险缓释的基本概念

  风险缓释（Credit Risk Mitigation, CRM）是指银行通过担保、抵质押、净额结算、
  信用衍生品等手段降低信用风险的措施。

  巴塞尔协议认可的缓释手段：
  1. 合格抵质押品
  2. 合格保证
  3. 合格信用衍生品（CDS等）
  4. 表内净额结算

二、抵质押管理

  2.1 合格抵质押品标准
    - 权属清晰，无争议
    - 可估值：有活跃交易市场或评估方法
    - 可变现：银行有能力处置
    - 法律有效：已办理合法登记手续

  2.2 抵质押率（LTV）
    LTV = 贷款金额 / 抵质押物评估价值
    
    常见监管/内部要求：
    - 住宅抵押：LTV ≤ 70%
    - 商业房产抵押：LTV ≤ 60%
    - 土地使用权抵押：LTV ≤ 60%
    - 机器设备抵押：LTV ≤ 50%
    - 存单/国债质押：LTV ≤ 90%（视币种、期限）
    - 上市公司股票质押：LTV ≤ 40-50%
    - 非上市股权质押：LTV ≤ 30%

  2.3 抵质押物价值管理
    - 初次评估：外部评估公司 + 银行内部审定
    - 定期重估：住宅类至少每年1次，商业类至少每季度1次
    - 动态监测：对价格波动大的（如股票），每日盯市
    - 警戒线/平仓线：质押物价值下降到一定比例，要求追加担保

  2.4 新一轮抵质押管理数字化
    - 抵质押物唯一编码管理
    - 押品估值模型（AVM）自动评估
    - 全国不动产登记信息实时对接
    - 押品处置平台线上化

三、保证管理

  3.1 保证人准入
    - 具备代偿能力的法人或自然人
    - 保证人需纳入统一授信，占用保证人自身的授信额度
    - 政府融资平台原则上不得作为企业贷款担保人

  3.2 保证方式
    - 一般保证：主债务人无法偿还时，保证人才承担责任 → 银行回收较慢
    - 连带责任保证：银行可直接向保证人追偿 → 银行权利更强

  3.3 保证评估
    - 保证人信用评级 → 确定保护程度
    - 保证覆盖率 = 保证金额 / 贷款金额
    - 部分保证（Partial Guarantee）vs 全额保证

四、信用衍生品

  - CDS（信用违约互换）：购买保护方支付保费，卖方承诺在参考实体信用事件发生时赔付
  - 主要用于大型企业贷款、债券投资的风险管理
  - 国内CDS市场尚在培育阶段，使用有限

4.5 预期损失（EL）与减值计提
================================================================================

一、预期损失的概念

  预期损失（Expected Loss, EL）是银行对信贷组合在正常经营中预期会发生的平均损失。
  
  EL = PD × LGD × EAD

  这是银行经营信贷业务的"成本"，应在贷款定价中覆盖。

二、减值计提体系（IFRS 9 / 中国新金融工具准则）

  2.1 三阶段模型

  ┌──────────────────────────────────────────────────────────┐
  │  阶段一：信用风险未显著增加（初次确认时）                 │
  │    - 计提12个月预期损失（12-month ECL）                   │
  │    - 利息收入按账面余额（Gross Carrying Amount）计算      │
  │    - 适用于：正常类贷款                                  │
  ├──────────────────────────────────────────────────────────┤
  │  阶段二：信用风险显著增加（SICR）                         │
  │    - 计提整个存续期内预期损失（Lifetime ECL）             │
  │    - 利息收入仍按账面余额计算                             │
  │    - 适用于：关注类贷款、PD大幅上升                      │
  ├──────────────────────────────────────────────────────────┤
  │  阶段三：已发生信用减值（Credit-Impaired）               │
  │    - 计提整个存续期内预期损失                              │
  │    - 利息收入按摊余成本（即账面余额 - 减值准备）计算       │
  │    - 适用于：不良类贷款（次级、可疑、损失）               │
  └──────────────────────────────────────────────────────────┘

  2.2 信用风险显著增加（SICR）的判断标准

    定量判断：
    - PD上升幅度超过绝对阈值（如PD增加超过2%）
    - PD上升幅度超过相对阈值（如当前PD > 初始PD的2倍）
    
    定性判断：
    - 贷款五级分类下调至关注类
    - 债务人列入银行内部预警名单
    - 债务人出现重大经营困难

    兜底条款：
    - 逾期超过30天，推定信用风险显著增加（可反驳）
    - 逾期超过90天，推定已减值（不可反驳）

  2.3 前瞻性调整

    IFRS 9要求减值计量考虑前瞻性信息（不能仅看历史数据），
    通常采用多情景加权法：

    ECL = 基准情景ECL × 基准概率 + 乐观情景ECL × 乐观概率 + 悲观情景ECL × 悲观概率

    前瞻性指标包括：GDP增速、CPI、PMI、失业率、房地产价格指数等。

  2.4 减值对银行的影响
    - 侵蚀当期利润
    - 影响资本充足率（减值准备不足部分从核心一级资本扣除）
    - IFRS 9下减值拨备显著增加（相比旧准则）且波动性更大
    - 顺周期性：经济下行时大量拨备，进一步压缩利润和资本

三、中国特色的减值管理

  3.1 拨备覆盖率
    拨备覆盖率 = 贷款减值准备 / 不良贷款余额
    监管要求 ≥ 150%（部分银行要求 ≥ 180%）

  3.2 贷款拨备率
    贷款拨备率 = 贷款减值准备 / 各项贷款余额
    监管要求 ≥ 2.5%

  3.3 "双高"要求
    银行需同时满足拨备覆盖率和贷款拨备率两项指标，
    按孰高原则执行。

================================================================================
4.6 非预期损失（UL）与经济资本
================================================================================

一、非预期损失（Unexpected Loss, UL）

  EL（预期损失）是统计平均数，UL是实际损失偏离平均数的程度（波动性/标准差）。
  
  UL衡量的是"在最坏情况下超过预期的损失"。
  
  如果EL = PD × LGD × EAD，则：
  UL = √[Var(Loss)] （损失的波动率）

二、经济资本（Economic Capital, EC）

  2.1 定义
    经济资本是银行根据自身风险状况，内部评估的为应对非预期损失所需的资本。
    不同于监管资本（按巴塞尔公式计算），经济资本更能反映银行真实风险。

  2.2 计算方法
    经济资本 = UL × 置信区间乘数
    
    - 置信水平通常取99.9%（与巴塞尔协议一致，即AA级评级标准）
    - 99.9%置信水平意味着：理论上1000年仅发生1次违约不足以用预提拨备覆盖

  2.3 经济资本的应用
    a) RAROC绩效评价
       RAROC = (收入 - 成本 - EL) / 经济资本
       用RAROC而非ROE衡量业务单元绩效

    b) 资本配置
       将有限的经济资本分配到RAROC最高的业务

    c) 风险定价
       确保贷款定价带来的RAROC高于最低回报率门槛

    d) 限额管理
       基于经济资本设定业务限额

三、监管资本 vs 经济资本对比

  ┌──────────────┬──────────────────┬──────────────────┐
  │              │ 监管资本          │ 经济资本          │
  ├──────────────┼──────────────────┼──────────────────┤
  │ 计算主体     │ 监管机构（巴塞尔）│ 银行内部          │
  │ 目标         │ 保护存款人和系统  │ 优化资本配置      │
  │ 风险覆盖     │ 标准化（一刀切）  │ 定制化（本行特征）│
  │ 置信水平     │ 99.9%            │ 银行自定（通常    │
  │              │                   │ ≥ 99.97%）       │
  │ 相关性假设   │ 监管给定公式      │ 银行自建模型      │
  │ 使用场景     │ 监管合规          │ 内部决策          │
  └──────────────┴──────────────────┴──────────────────┘
