# Markdown文本转待办任务清单

## 功能概述

将非结构化的Markdown任务文本转换为规范化的Excel待办任务表，自动完成：
1. 任务去重合并
2. 工作量估算（人天）
3. 计划时间计算
4. 负责人识别
5. 统一格式输出

## 工作流程

### 1. 分析输入文本
- 识别任务条目（通常包含负责人、任务描述、状态等）
- 提取关键信息：负责人、任务内容、优先级、当前状态

### 2. 任务去重
- 合并相似或重复的任务描述
- 保留最完整的任务信息
- 统一任务表述

### 3. 工作量估算
根据任务类型和复杂度估算人天：
| 任务类型 | 简单(3天) | 中等(5天) | 复杂(8天) |
|---------|----------|----------|----------|
| 开发任务 | 配置修改、简单接口 | 功能开发、联调 | 架构改造、性能优化 |
| 前端任务 | UI调整、样式修复 | 组件开发、交互优化 | 框架升级、性能优化 |
| 性能任务 | 参数调优 | SQL优化、缓存优化 | 架构优化、压测 |
| 安全任务 | 配置加密 | 漏洞修复 | 安全组件开发 |

### 4. 生成Excel
执行 `scripts/md2todo.py` 脚本生成Excel文件：

```bash
python scripts/md2todo.py --input <md文件路径> --output <excel输出路径> [--owner <登记人>] [--group <所属小组>]
```

### 5. 输出格式
Excel包含以下字段：
- 登记时间 (YYYY-MM-DD)
- 登记人
- 事项分类 (开发/前端/性能/安全/数据/设计/配置)
- 小组
- 事项描述
- 优先级 (高/中/低)
- 参与人员
- 进度 (未开始/进行中/已完成)
- 计划开始时间 (YYYY-MM-DD)
- 计划完成时间 (YYYY-MM-DD)
- 负责人
- 涉及关联人员/组
- 进度说明

## 使用示例

### 示例1：基本用法
用户输入：
```
请把以下任务整理成待办清单：
李富强--防止查询大数据量--SQL拦截器，再排期
张勋文--流程轨迹权限功能开发，未开始
王微--环境yaml参数统一，进行中
```

执行步骤：
1. 读取任务文本
2. 识别3个独立任务
3. 估算工作量：李富强(5天)、张勋文(5天)、王微(3天)
4. 生成Excel：`待办任务清单.xlsx`

### 示例2：指定登记信息
```bash
python scripts/md2todo.py --input tasks.md --output 待办清单.xlsx --owner "刘贵斌" --group "公共组"
```

## 任务识别规则

### 支持的文本格式
1. **标准格式**：`负责人--任务描述--状态`
2. **列表格式**：`- [ ] 负责人：任务内容`
3. **表格格式**：Markdown表格中的任务行
4. **混合格式**：包含已完成和未完成任务的混合文本

### 状态识别
- 未开始："未开始"、"待排期"、"排期中"
- 进行中："进行中"、"开发中"、"已完成xx%"
- 已完成："已完成"、"已结束"、"Done"

### 优先级判断
- **高**：性能优化、安全相关、核心功能
- **中**：常规开发、功能完善
- **低**：UI优化、文档整理

## 脚本说明

### scripts/md2todo.py
主要功能：
- 解析Markdown任务文本
- 任务去重与合并
- 自动估算工作量
- 计算计划时间
- 生成格式化Excel

参数说明：
- `--input, -i`: 输入Markdown文件路径
- `--output, -o`: 输出Excel文件路径
- `--owner`: 登记人姓名（默认：当前用户）
- `--group`: 所属小组（默认：公共组）
- `--start-date`: 计划开始日期（默认：当天）

## 注意事项

1. **日期格式**：统一使用 `YYYY-MM-DD` 格式
2. **工作量估算**：基于经验值估算，可根据实际情况调整
3. **任务去重**：基于相似度算法，需人工复核确认
4. **负责人识别**：基于文本中的姓名，需确保姓名准确
