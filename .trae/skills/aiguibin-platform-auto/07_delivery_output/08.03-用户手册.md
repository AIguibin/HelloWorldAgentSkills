## 功能模块

### 1. 系统设置

#### 1.1 用户管理

**功能说明**: 管理系统用户账号

**操作步骤**:
1. 点击左侧菜单"系统设置" → "用户管理"
2. 查看用户列表
3. 点击"新增"按钮添加用户
4. 点击"编辑"按钮修改用户信息
5. 点击"删除"按钮删除用户

**字段说明**:

| 字段 | 说明 | 必填 |
|-----|------|------|
| 用户编号 | 员工编号 | 是 |
| 用户名 | 登录账号 | 是 |
| 真实姓名 | 用户姓名 | 是 |
| 邮箱 | 电子邮箱 | 否 |
| 手机号 | 联系电话 | 否 |
| 所属机构 | 默认机构 | 是 |
| 所属部门 | 默认部门 | 否 |

#### 1.2 角色管理

**功能说明**: 管理系统角色和权限

**操作步骤**:
1. 点击左侧菜单"系统设置" → "角色管理"
2. 查看角色列表
3. 点击"新增"按钮添加角色
4. 点击"权限配置"按钮设置角色权限

#### 1.3 机构管理

**功能说明**: 管理组织机构

**操作步骤**:
1. 点击左侧菜单"系统设置" → "机构管理"
2. 查看机构树形结构
3. 点击"新增"按钮添加机构
4. 点击"编辑"按钮修改机构信息

### 2. 数据库管理

#### 2.1 数据库比对

**功能说明**: 比对数据库与设计文档差异

**操作步骤**:
1. 点击左侧菜单"数据库管理" → "数据库比对"
2. 选择要比对的环境(DEV/SIT/UAT)
3. 点击"执行比对"按钮
4. 等待比对完成
5. 查看比对结果

**比对结果说明**:

| 差异类型 | 说明 |
|---------|------|
| 表差异 | 设计文档与数据库表不一致 |
| 字段差异 | 字段类型、长度、是否为空等不一致 |
| 索引差异 | 索引定义不一致 |
| 贯标异常 | 字段不符合贯标规范 |

#### 2.2 定时任务配置

**功能说明**: 配置数据库比对定时任务

**操作步骤**:
1. 点击左侧菜单"数据库管理" → "定时任务配置"
2. 查看定时任务列表
3. 点击"编辑"按钮修改任务配置
4. 设置Cron表达式
5. 启用/禁用任务

**Cron表达式说明**:

| 表达式 | 说明 |
|-------|------|
| 0 0 2 * * ? | 每天2点执行 |
| 0 0 4 * * ? | 每天4点执行 |
| 0 0 6 * * ? | 每天6点执行 |

#### 2.3 执行记录

**功能说明**: 查看数据库比对执行记录

**操作步骤**:
1. 点击左侧菜单"数据库管理" → "执行记录"
2. 查看执行记录列表
3. 点击"查看详情"查看比对结果
4. 点击"下载结果"下载Excel文件

## 常见问题

### Q1: 忘记密码怎么办?

**A**: 请联系系统管理员重置密码。

### Q2: 登录时提示"账号已锁定"?

**A**: 连续5次密码错误会锁定账号，请联系管理员解锁。

### Q3: 数据库比对执行时间过长?

**A**: 全环境比对涉及多个数据库，执行时间较长属于正常现象，请耐心等待。

### Q4: 比对结果在哪里查看?

**A**: 比对结果会自动上传到SVN，也可以在"执行记录"页面下载。
