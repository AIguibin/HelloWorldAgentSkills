## 部署步骤

### 方式一: 传统部署

#### 1. 环境准备

```bash
# 安装JDK 17
yum install java-17-openjdk java-17-openjdk-devel

# 安装MySQL 8.0
yum install mysql-server

# 安装Redis
yum install redis
```

#### 2. 数据库初始化

```bash
# 创建数据库
mysql -u root -p
CREATE DATABASE platform_config DEFAULT CHARACTER SET utf8mb4;

# 执行建表脚本
mysql -u root -p platform_config < db/schema.sql

# 执行初始数据脚本
mysql -u root -p platform_config < db/init_data.sql
```

#### 3. 配置文件修改

```yaml
# application-prod.yml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/platform_config
    username: ${DB_USERNAME}
    password: ${DB_PASSWORD}
  
  redis:
    host: ${REDIS_HOST}
    port: 6379
    password: ${REDIS_PASSWORD}

jwt:
  secret: ${JWT_SECRET}
```

#### 4. 启动应用

```bash
# 打包
mvn clean package -DskipTests

# 启动
java -jar target/aiguibin-platform-arch.jar \
  --spring.profiles.active=prod \
  -Xms512m -Xmx1024m
```

### 方式二: Docker部署

#### 1. 构建镜像

```bash
# 构建镜像
docker build -t aiguibin-platform:1.0.0 .
```

#### 2. Docker Compose部署

```yaml
# docker-compose.yml
version: '3.8'
services:
  app:
    image: aiguibin-platform:1.0.0
    ports:
      - "8080:8080"
    environment:
      - SPRING_PROFILES_ACTIVE=prod
      - DB_HOST=mysql
      - DB_USERNAME=root
      - DB_PASSWORD=root123
      - REDIS_HOST=redis
      - JWT_SECRET=your-secret-key
    depends_on:
      - mysql
      - redis
    networks:
      - app-network

  mysql:
    image: mysql:8.0
    environment:
      - MYSQL_ROOT_PASSWORD=root123
      - MYSQL_DATABASE=platform_config
    volumes:
      - mysql-data:/var/lib/mysql
      - ./db:/docker-entrypoint-initdb.d
    networks:
      - app-network

  redis:
    image: redis:7.0
    volumes:
      - redis-data:/data
    networks:
      - app-network

volumes:
  mysql-data:
  redis-data:

networks:
  app-network:
```

```bash
# 启动服务
docker-compose up -d
```

## Nginx配置

```nginx
# /etc/nginx/conf.d/platform.conf
upstream backend {
    server 127.0.0.1:8080;
}

server {
    listen 80;
    server_name platform.example.com;
    
    # HTTPS重定向
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl;
    server_name platform.example.com;
    
    ssl_certificate /etc/nginx/ssl/cert.pem;
    ssl_certificate_key /etc/nginx/ssl/key.pem;
    
    location / {
        root /opt/platform/static;
        try_files $uri $uri/ /index.html;
    }
    
    location /api/ {
        proxy_pass http://backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

## 常见问题

### 1. 启动失败

**问题**: 应用启动失败，提示数据库连接失败
**解决**: 检查数据库服务是否启动，检查连接配置是否正确

### 2. 内存不足

**问题**: 应用运行一段时间后内存不足
**解决**: 调整JVM参数，增加-Xmx值

### 3. SVN连接失败

**问题**: 数据库比对模块SVN连接失败
**解决**: 检查SVN服务器地址和认证信息
