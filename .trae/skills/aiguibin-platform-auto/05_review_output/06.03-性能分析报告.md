## 性能优化建议

### 高优先级

#### 1. 权限数据缓存

```java
// 优化前: 每次请求查询数据库
List<String> permissions = userService.getUserPermissions(userId);

// 优化后: 使用Redis缓存
@Cacheable(value = "user:permissions", key = "#userId")
public List<String> getUserPermissions(Long userId) {
    return userMapper.selectUserPermissions(userId);
}
```

#### 2. 批量数据库操作

```java
// 优化前: 循环单条插入
for (DbExecuteDetail detail : details) {
    detailMapper.insert(detail);
}

// 优化后: 批量插入
detailMapper.insertBatch(details);
```

### 中优先级

#### 3. 连接池优化

```yaml
spring:
  datasource:
    hikari:
      maximum-pool-size: 20
      minimum-idle: 5
      connection-timeout: 30000
      idle-timeout: 600000
      max-lifetime: 1800000
```

#### 4. 异步处理

```java
// 异步发送通知
@Async
public void sendNotification(String message) {
    feiQService.send(message);
}
```

### 低优先级

#### 5. SQL优化

```sql
-- 添加复合索引
CREATE INDEX idx_user_status ON sys_user(status, deleted);
CREATE INDEX idx_record_env_time ON db_execute_record(env, create_time);
```
