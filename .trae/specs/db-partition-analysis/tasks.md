- [ ] Task 1: 读取现有分区清单，获取已标注表信息

- [ ] Task 2: 读取全部22个数据库设计文档，提取所有表及字段结构
  - [ ] 遍历 `EE-湖北农信新信贷数据库设计文档` 下所有Excel文件
  - [ ] 每个文件，跳过"修订记录""索引目录"等非表Sheet，根据"目录"sheet，遍历每个表sheet页

  - [ ] 汇总所有表清单
- [ ] Task 3: 逐表分析分区需求
  - [ ] 对于已在分区清单中的表（G列="是"）：补充完善分区键、分区数、分区策略、备注
  - [ ] 对于不在分区清单中的表：根据字段结构分析是否需要分区
  - [ ] 分析规则：日志类/历史类/大业务量表 → 必须分区；配置/字典/小表 → 可不分区

  - [ ] 估算分区数：根据数据量级评估初始分区数
- [ ] Task 4: 生成完整分区清单Excel
  - [ ] 按现有格式（A-K列）输出完整清单

  - [ ] C列：所属模块
  - [ ] D列：责任人
  - [ ] E列：表名（英文）
  - [ ] F列：表名（中文）
  - [ ] G列：是否表分区（是/否）
  - [ ] H列：表分区键
  - [ ] I列：初始表分区数
  - [ ] J列：表分区策略
  - [ ] K列：备注
