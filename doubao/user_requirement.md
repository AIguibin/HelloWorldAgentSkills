## 1. 项目概述

### 1.1 项目背景
企业级架构管理平台，提供从数据库设计、接口管理、配置管理到开发规范的全生命周期架构管理能力。

### 1.2 项目目标
基于现有文档，补充完善并生成完整可运行的代码，包含：
- 完整的后端API实现
- 完整的单元测试
- Knife4j接口文档
- 完整的数据库建表SQL

## 2. 功能需求

### 2.1 核心模块（必实现）

#### 2.1.1 系统设置模块
| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 用户管理 | P0 | 用户列表、新增、编辑、删除、锁定/解锁、密码重置 |
| 机构管理 | P0 | 机构列表、新增、编辑、删除 |
| 部门管理 | P0 | 部门列表、新增、编辑、删除 |
| 角色管理 | P0 | 角色列表、新增、编辑、删除、分配权限、分配用户 |
| 菜单管理 | P0 | 菜单列表、新增、编辑、删除 |
| 审计日志 | P0 | 操作日志、登录日志、日志查询 |

#### 2.1.2 认证授权模块
| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 两步登录 | P0 | 账号密码验证 → 机构选择 |
| Token机制 | P0 | Access Token（30分钟）、Refresh Token（7天）、CSRF Token |
| 账号锁定 | P0 | 连续5次密码错误自动锁定 |
| RBAC权限 | P0 | 角色-菜单-按钮权限 |
| 数据权限 | P0 | 全部/本机构/本部门/本人 |

#### 2.1.3 数据库比对模块
| 功能点 | 优先级 | 说明 |

| Excel解析 | P0 | 目录Sheet、字段Sheet、索引Sheet |
| 表/字段/索引比对 | P0 | 多环境数据库结构比对 |
| 差异结果输出 | P0 | Excel输出（字段差异、表差异、索引差异） |
| 定时任务 | P0 | DEV 02:00, SIT 04:00, UAT 06:00 |
| SVN集成 | P1 | 使用本地文件系统替代 |

## 3. 非功能需求

### 3.1 性能需求
- 响应时间：API接口响应时间 < 500ms（P0）
- 并发支持：支持100+并发用户（P1）
- 数据库比对：单环境比对时间 < 5分钟（P0）

### 3.2 安全需求
- 密码加密：BCrypt加密存储（P0）
- Token机制：JWT + Refresh Token（P0）
- 权限控制：RBAC + 数据权限（P0）
- SQL注入防护：MyBatis-Plus参数化查询（P0）

### 3.3 可靠性需求
- 系统可用性：99.5%+（P1）
- 数据一致性：事务保证（P0）
- 异常处理：全局异常处理器（P0）
