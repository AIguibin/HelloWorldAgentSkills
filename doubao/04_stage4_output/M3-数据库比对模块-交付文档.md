## 3. 核心功能实现

### 3.1 数据源配置管理

#### 功能特性
- **分页查询**: 支持按环境、数据源名称、启用状态筛选
- **全量列表**: 获取所有启用的数据源
- **数据源详情**: 获取数据源完整信息
- **创建数据源**: 自动生成创建和更新时间
- **更新数据源**: 支持部分字段更新
- **删除数据源**: 安全删除
- **连接测试**: 支持按ID测试和按配置测试两种方式
- **多数据库支持**: MySQL、Oracle

#### 接口列表
| 接口 | 方法 | 说明 |
|------|------|------|
| /api/db/datasources/page | GET | 分页查询数据源列表 |
| /api/db/datasources/all | GET | 获取所有启用的数据源 |
| /api/db/datasources/{dsId} | GET | 获取数据源详情 |
| /api/db/datasources | POST | 创建数据源 |
| /api/db/datasources | PUT | 更新数据源 |
| /api/db/datasources/{dsId} | DELETE | 删除数据源 |
| /api/db/datasources/{dsId}/test | POST | 测试数据源连接（按ID） |
| /api/db/datasources/test | POST | 测试数据源连接（按配置） |

---

### 3.2 数据库连接测试

#### 支持的数据库类型
- **MySQL**: com.mysql.cj.jdbc.Driver
- **Oracle**: oracle.jdbc.OracleDriver

#### JDBC URL构建
**MySQL**:
```
jdbc:mysql://{host}:{port}/{dbName}?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
```

**Oracle**:
```
jdbc:oracle:thin:@{host}:{port}:{dbName}
```

#### 连接验证
- 使用 `conn.isValid(5)` 验证连接有效性
- 超时时间设置为5秒
- 完整的异常捕获和错误提示

---

### 3.3 执行记录管理

#### 功能特性
- **分页查询**: 支持按环境、状态筛选
- **记录详情**: 获取执行记录完整信息
- **记录状态**: PENDING/RUNNING/SUCCESS/FAILED

## 6. 技术实现要点

### 6.1 数据库连接池
- 使用Druid连接池（已在M0阶段配置）
- 支持动态数据源路由
- 连接参数可配置

### 6.2 连接测试
- 直接使用JDBC DriverManager测试
- 不依赖连接池，确保真实连接可用
- 5秒超时保护
- 完整的异常信息返回

### 6.3 事务管理
- 使用@Transactional注解
- rollbackFor = Exception.class确保异常回滚
- 数据源CRUD操作启用事务

### 6.4 数据验证
- 使用Jakarta Validation注解
- @NotBlank、@NotNull等验证
- 数据源标识唯一性检查

## 9. 注意事项

### 9.1 密码安全
- 生产环境应加密存储数据库密码
- 建议使用Jasypt加密配置文件中的密码
- 不要在日志中输出完整密码

### 9.2 连接安全
- 生产环境建议使用SSL连接
- 限制数据库访问IP白名单
- 定期更换数据库密码

### 9.3 资源管理
- 数据库连接使用后及时关闭
- 结果文件定期清理
- 大Excel文件注意内存占用
