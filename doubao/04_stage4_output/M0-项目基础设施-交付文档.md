## 6. 快速开始指南

### 6.1 环境要求
- JDK 17+
- Maven 3.8+
- MySQL 8.0+

### 6.2 数据库初始化
```bash
# 1. 创建数据库并执行初始化脚本
mysql -u root -p < src/main/resources/schema.sql

# 2. 插入测试数据
mysql -u root -p platform_config < src/main/resources/data.sql
```

### 6.3 修改配置
编辑 `application-dev.yml`，修改数据库连接信息：
```yaml
spring:
  datasource:
    dynamic:
      datasource:
        master:
          url: jdbc:mysql://localhost:3306/platform_config?...
          username: root
          password: your_password
```

### 6.4 启动项目
```bash
cd aiguibin-platform-arch
mvn clean install
mvn spring-boot:run
```

### 6.5 访问接口文档
启动成功后访问：http://localhost:8080/api/doc.html

### 6.6 测试接口
- 健康检查: GET /api/test/health
- 欢迎页面: GET /api/test/welcome

## 10. 风险与注意事项

### 10.1 风险点
1. **MySQL版本兼容性**: 确保使用MySQL 8.0+版本
2. **JDK版本**: 必须使用JDK 17+，不兼容JDK 8或11
3. **数据库连接**: 启动前需确保MySQL服务已启动并可连接

### 10.2 注意事项
1. **密码加密**: data.sql中的密码是示例值，实际使用时应重新生成BCrypt加密密码
2. **配置安全**: 生产环境切勿将application-dev.yml提交到Git仓库
3. **文件路径**: 确保uploads和results目录有写入权限
