## 1. 接口设计规范

### 1.1 统一响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {},
  "timestamp": 1705910400000
}
```

### 1.2 状态码定义

| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未登录/Token过期 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 1.3 接口路径规范
- 格式：`/api/{模块}/{资源}/{操作}`
- 示例：`/api/auth/login`, `/api/system/user/list`

---

## 2. 认证授权模块接口

### 2.1 第一步登录 - 账号密码验证

**接口路径**: `POST /api/auth/login-step1`

**请求参数**:
```json
{
  "username": "admin",
  "password": "admin123"
}
```

**响应数据**:
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "userId": 1,
    "username": "admin",
    "realName": "超级管理员",
    "orgList": [
      {
        "orgCode": "100000",
        "orgName": "总公司"
      },
      {
        "orgCode": "110000",
        "orgName": "北京分公司"
      }
    ]
  }
}
```

### 2.2 第二步登录 - 选择机构

**接口路径**: `POST /api/auth/login-step2`

**请求参数**:
```json
{
  "userId": 1,
  "orgCode": "100000"
}
```

**响应数据**:
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expiresIn": 1800,
    "userInfo": {
      "userId": 1,
      "username": "admin",
      "realName": "超级管理员",
      "orgCode": "100000",
      "orgName": "总公司",
      "deptCode": "100100",
      "deptName": "技术部"
    }
  }
}
```

### 2.3 刷新Token

**接口路径**: `POST /api/auth/refresh`

**请求参数**:
```json
{
  "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

### 2.4 退出登录

**接口路径**: `POST /api/auth/logout`

**请求头**: `Authorization: Bearer {accessToken}`

## 5. 总结

本接口设计包含以下模块的接口：

1. **认证授权模块**: 两步登录、Token刷新、退出登录
2. **系统设置模块**: 用户、机构、部门、角色、菜单、日志管理
3. **数据库比对模块**: 数据源配置、比对执行、定时任务

所有接口遵循统一响应格式，使用JWT Token认证，支持Knife4j在线文档。
