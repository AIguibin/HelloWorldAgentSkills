## 1. 认证授权模块详细设计

### 1.1 两步登录流程

#### Step 1: 账号密码验证
1. 用户输入用户名和密码
2. 后端验证用户名是否存在
3. 后端验证密码是否正确（BCrypt比对）
4. 查询用户关联的机构列表
5. 返回用户信息和机构列表

#### Step 2: 选择机构
1. 用户选择登录机构
2. 验证用户是否有权限访问该机构
3. 生成Access Token（30分钟）
4. 生成Refresh Token（7天）
5. 记录登录日志
6. 返回Token和用户信息

### 1.2 JWT Token生成与验证

#### Token结构
```
Header: {
  "alg": "HS256",
  "typ": "JWT"
}

Payload: {
  "userId": 1,
  "username": "admin",
  "orgCode": "100000",
  "exp": 1705912200,
  "iat": 1705910400
}

Signature: HMACSHA256(base64UrlEncode(header) + "." + base64UrlEncode(payload), secret)
```

#### 验证流程
1. 从请求头获取Token
2. 验证Token签名
3. 验证Token是否过期
4. 解析Payload获取用户信息
5. 将用户信息存入SecurityContext

### 1.3 权限检查机制

#### 权限注解
```java
@PreAuthorize("@ss.hasPermission('user:add')")
public Result addUser(@RequestBody UserDTO userDTO) {
    // ...
}
```

#### 权限检查逻辑
1. 获取当前登录用户
2. 查询用户拥有的角色
3. 查询角色关联的菜单权限
4. 判断用户是否拥有所需权限
5. 有权限则放行，无权限则返回403

## 2. Excel解析详细设计

### 2.1 目录Sheet解析

#### Sheet结构
| 序号 | 表英文名 | 表中文名 | 模块 | 备注 |
|------|---------|---------|------|------|
| 1 | sys_user | 用户表 | 系统管理 | - |

#### 解析逻辑
1. 定位起始行（从第14行开始）
2. 遍历每一行数据
3. 读取表英文名、表中文名、模块
4. 存储到内存对象

### 2.2 字段Sheet解析

#### Sheet结构
| 表英文名 | 字段英文名 | 字段中文名 | 类型 | 长度 | 允许空 | 默认值 | 说明 |
|---------|-----------|-----------|------|------|--------|--------|------|
| sys_user | id | 主键ID | BIGINT | - | 否 | - | 自增主键 |

#### 解析逻辑
1. 遍历每一行数据
2. 读取表英文名关联到对应表
3. 读取字段信息（英文名、中文名、类型、长度等）
4. 存储到表的字段列表

### 2.3 索引Sheet解析

#### Sheet结构
| 表英文名 | 索引名 | 索引类型 | 索引字段 | 说明 |
|---------|--------|---------|---------|------|
| sys_user | uk_username | UNIQUE | username | 唯一索引 |

#### 解析逻辑
1. 遍历每一行数据
2. 读取表英文名关联到对应表
3. 读取索引信息（索引名、类型、字段）
4. 存储到表的索引列表

## 3. 数据库比对详细设计

### 3.1 比对流程

1. **Excel解析**：读取Excel文档，解析目录、字段、索引
2. **数据库元数据查询**：连接数据库，查询表、字段、索引信息
3. **表比对**：比对表的新增、删除
4. **字段比对**：比对字段的新增、删除、修改
5. **索引比对**：比对索引的新增、删除、修改
6. **贯标检查**：检查字段是否符合标准
7. **生成结果**：生成比对结果Excel
8. **保存记录**：保存比对记录和明细到数据库

### 3.2 表比对

| 比对项 | 说明 |
|--------|------|
| 新增表 | Excel有，数据库无 |
| 删除表 | Excel无，数据库有 |
| 表名一致 | 表英文名相同 |

### 3.3 字段比对

| 比对项 | 说明 |
|--------|------|
| 新增字段 | Excel有，数据库无 |
| 删除字段 | Excel无，数据库有 |
| 字段类型不一致 | 字段类型不同 |
| 字段长度不一致 | 字段长度不同 |
| 允许空不一致 | 允许空属性不同 |
| 默认值不一致 | 默认值不同 |
| 字段注释不一致 | 注释不同 |

### 3.4 索引比对

| 比对项 | 说明 |
|--------|------|
| 新增索引 | Excel有，数据库无 |
| 删除索引 | Excel无，数据库有 |
| 索引类型不一致 | 索引类型不同 |
| 索引字段不一致 | 索引字段不同 |

### 3.5 贯标检查

#### 检查规则
1. 检查字段英文名是否符合标准
2. 检查字段类型是否符合标准
3. 检查字段注释是否符合标准
4. 标准来源于 db_standard_field 表
