## 2. 架构设计核心内容

### 2.1 技术栈

| 类别 | 技术选型 | 版本 |
|------|---------|------|
| 后端框架 | Spring Boot | 3.2.5 |
| 编程语言 | Java | 17 |
| ORM框架 | MyBatis-Plus | 3.5.6 |
| 数据库 | MySQL | 8.0 |
| 连接池 | Druid | 1.2.22 |
| Excel处理 | EasyExcel | 3.3.4 |
| 动态数据源 | dynamic-datasource | 4.3.0 |
| 本地缓存 | Caffeine | 3.1.8 |
| 接口文档 | Knife4j | 4.4.0 |
| 前端框架 | Vue | 3.4.21 |
| 构建工具 | Vite | 5.2.0 |
| UI组件库 | Element Plus | 2.6.3 |

### 2.2 系统架构
- **架构模式**: 微内核 + 插件式架构
- **分层架构**: 前端层 → 应用层 → 服务层 → 数据访问层 → 数据层
- **核心模块**: 认证授权、系统设置
- **插件模块**: 数据库比对、定时任务

### 2.3 数据库设计
- **数据库**: MySQL 8.0
- **字符集**: utf8mb4
- **存储引擎**: InnoDB
- **表数量**: 15张核心表
- **核心表**:
  - 用户管理: sys_user, sys_user_org
  - 机构部门: sys_org, sys_dept
  - 角色权限: sys_role, sys_user_role, sys_menu, sys_role_menu
  - 审计日志: sys_oper_log, sys_login_log
  - 数据库比对: db_datasource_config, db_execute_record, db_execute_detail 等
  - 系统配置: sys_config

### 2.4 认证授权
- **登录方式**: 两步登录（账号密码 + 选择机构）
- **认证方式**: JWT Token
- **Token有效期**: Access Token 30分钟，Refresh Token 7天
- **权限模型**: RBAC + 数据权限（全部/本机构/本部门/本人）

### 2.5 核心功能模块

#### 2.5.1 系统设置模块
- 用户管理：CRUD、重置密码、锁定/解锁
- 机构管理：树形结构、CRUD
- 部门管理：树形结构、CRUD
- 角色管理：CRUD、分配菜单权限
- 菜单管理：树形结构、CRUD
- 审计日志：操作日志、登录日志查询

#### 2.5.2 数据库比对模块
- 数据源配置：CRUD、测试连接
- Excel解析：目录Sheet、字段Sheet、索引Sheet
- 数据库比对：表比对、字段比对、索引比对、贯标检查
- 结果生成：生成比对结果Excel
- 定时任务：Cron配置、任务调度、执行记录

## 4. 风险与替代方案

### 4.1 已识别的风险
1. **本地缓存**: 分布式环境下缓存不一致（替代方案：后续可扩展为Redis）
2. **动态数据源**: 数据源管理复杂度高（已有完整的配置和管理机制）
3. **Excel大文件**: 内存占用可能较高（替代方案：后续可使用流式解析）

### 4.2 用户确认的替代方案
根据用户确认，以下替代方案已采用：
- ✅ 使用Caffeine本地缓存替代Redis
- ✅ 使用本地文件系统替代SVN（可选）
- ✅ 禁用飞秋通知（可选）
- ✅ 先实现后端API，提供Knife4j接口文档
