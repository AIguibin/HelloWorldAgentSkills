## 2. 详细里程碑计划

### 2.1 里程碑M1：项目基础设施完成

**时间**: Day 1 - Day 5  
**工期**: 5天  
**目标**: 搭建项目基础设施，可开始业务开发

**交付物清单**:
- [ ] Maven项目结构（pom.xml）
- [ ] application.yml主配置文件
- [ ] application-dev.yml开发环境配置
- [ ] 数据库初始化脚本（schema.sql + data.sql）
- [ ] 公共模块（Result、Exception、Constant、Util）
- [ ] MyBatis-Plus配置
- [ ] Knife4j接口文档配置
- [ ] Caffeine缓存配置
- [ ] M0阶段测试报告

**验收标准**:
- Maven项目可正常编译
- 数据库可正常初始化
- Knife4j文档页面可访问
- 公共模块单元测试通过

---

### 2.2 里程碑M2：认证授权模块完成

**时间**: Day 6 - Day 17  
**工期**: 12天  
**目标**: 用户可登录系统，权限控制生效

**交付物清单**:
- [ ] 认证相关实体类（SysUser、SysRole、SysMenu等）
- [ ] 认证相关Mapper接口
- [ ] JwtTokenProvider工具类
- [ ] 密码加密工具类
- [ ] JwtAuthenticationFilter认证过滤器
- [ ] PermissionService权限服务
- [ ] DataScopeAspect数据权限切面
- [ ] AuthService认证服务（两步登录）
- [ ] AuthController认证接口
- [ ] 认证授权模块单元测试
- [ ] M1阶段集成测试报告

**验收标准**:
- 第一步：账号密码验证成功，返回机构列表
- 第二步：选择机构成功，返回JWT Token
- Token验证成功，用户信息正确
- RBAC权限验证生效
- 数据权限过滤生效
- 接口文档完整，可在线调试

---

### 2.3 里程碑M3：系统设置模块完成

**时间**: Day 18 - Day 43  
**工期**: 26天  
**目标**: 系统设置功能完整，可管理用户、机构、角色、菜单

**交付物清单**:
- [ ] 用户管理功能（CRUD、重置密码、锁定/解锁）
- [ ] 机构管理功能（树形结构、CRUD）
- [ ] 部门管理功能（树形结构、CRUD）
- [ ] 角色管理功能（CRUD、分配菜单、分配用户）
- [ ] 菜单管理功能（树形结构、CRUD）
- [ ] 审计日志功能（操作日志、登录日志）
- [ ] OperLogAspect操作日志切面
- [ ] 系统设置模块单元测试
- [ ] M2阶段集成测试报告

**验收标准**:
- 用户列表可分页查询、筛选
- 用户可新增、编辑、删除、重置密码、锁定/解锁
- 机构/部门树形结构展示正常
- 角色可分配菜单权限
- 菜单树形结构展示正常
- 操作日志自动记录
- 登录日志可查询
- 所有功能接口测试通过
