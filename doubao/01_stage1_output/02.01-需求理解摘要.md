## 一、需求概述

### 1.1 项目定位
企业级架构管理平台，提供从数据库设计、接口管理、配置管理到开发规范的全生命周期架构管理能力。

### 1.2 核心目标
基于现有文档，补充完善并生成完整可运行的代码，包含：
- 完整的后端API实现
- 完整的单元测试
- Knife4j接口文档
- 完整的数据库建表SQL

### 1.3 执行范围
优先实现以下3个核心模块：
1. **系统设置模块** - 用户/机构/部门/角色/菜单/审计日志
2. **认证授权模块** - 两步登录/JWT/RBAC/数据权限
3. **数据库比对模块** - 多数据源配置/Excel解析/比对/输出

## 二、核心业务理解

### 2.1 系统设置模块

#### 2.1.1 用户管理
- 支持用户的增删改查
- 支持账号锁定/解锁
- 支持密码重置
- 用户可关联多个机构，设置默认机构

#### 2.1.2 机构管理
- 树形结构展示机构层级
- 支持机构的增删改查
- 有下级机构时不可删除

#### 2.1.3 角色管理
- 支持角色的增删改查
- 支持为角色分配菜单权限
- 支持为角色分配用户
- 支持数据权限配置（全部/本机构/本部门/本人）

#### 2.1.4 审计日志
- 记录用户操作日志
- 记录用户登录日志
- 支持多维度日志查询

### 2.2 认证授权模块

#### 2.2.1 两步登录流程
```
第一步：账号密码验证
├─ 输入用户名、密码
├─ 验证账号密码正确性
├─ 检查账号是否锁定
├─ 获取用户所属机构列表
└─ 返回Token和机构列表

第二步：机构选择
├─ 选择登录机构
├─ 验证用户机构权限
├─ 生成最终访问Token
├─ 生成CSRF Token
└─ 登录成功
```

#### 2.2.2 Token机制
- Access Token：有效期30分钟
- Refresh Token：有效期7天
- CSRF Token：会话级

#### 2.2.3 账号安全
- 连续5次密码错误自动锁定
- 密码BCrypt加密存储
- 支持管理员手动锁定/解锁

### 2.3 数据库比对模块

#### 2.3.1 多数据源配置
- DEV环境：7个数据库
- SIT环境：7个数据库
- UAT环境：12个数据库

#### 2.3.2 比对流程
1. 从Excel文档读取表结构（目录Sheet、字段Sheet、索引Sheet）
2. 从实际数据库读取表结构
3. 执行表/字段/索引比对
4. 生成差异结果Excel（字段差异、表差异、索引差异）

#### 2.3.3 定时任务
- DEV环境：每天02:00执行
- SIT环境：每天04:00执行
- UAT环境：每天06:00执行

## 五、非功能需求理解

### 5.1 性能需求
- API接口响应时间 < 500ms
- 支持100+并发用户

### 5.2 安全需求
- 密码BCrypt加密存储
- JWT + Refresh Token机制
- RBAC + 数据权限
- MyBatis-Plus参数化查询防SQL注入

### 5.3 质量要求
- 行覆盖率 ≥ 80%
- 分支覆盖率 ≥ 70%
- 方法覆盖率 = 100%
- 遵循阿里巴巴Java开发规范
