## 三、核心功能模块

### 3.1 系统设置模块
- 用户管理：用户列表、新增、编辑、删除、锁定/解锁、密码重置
- 机构管理：机构列表（树形）、新增、编辑、删除
- 部门管理：部门列表、新增、编辑、删除
- 角色管理：角色列表、新增、编辑、删除、分配权限、分配用户
- 菜单管理：菜单列表（树形）、新增、编辑、删除
- 审计日志：操作日志、登录日志、日志查询

### 3.2 认证授权模块
- 两步登录：账号密码验证 → 机构选择
- Token机制：Access Token（30分钟）、Refresh Token（7天）、CSRF Token（会话级）
- 账号锁定策略：连续5次密码错误自动锁定
- 权限模型：RBAC + 数据权限（全部/本机构/本部门/本人）

### 3.3 数据库比对模块（核心功能）
- 数据源配置：多环境多数据库配置（DEV:7个, SIT:7个, UAT:12个）
- 比对执行模式：单环境多数据库比对、全环境比对
- 输出文档：字段差异汇总.xlsx、表差异汇总.xlsx、索引差异汇总.xlsx、贯标检查结果.xlsx
- 定时任务配置：DEV(02:00)、SIT(04:00)、UAT(06:00)
- SVN集成：设计文档更新、结果文件上传
- 飞秋通知：每个数据库比对完成后发送通知

## 四、架构设计信息

### 4.1 架构风格
- **微内核 + 插件式架构**
  - 核心平台提供基础能力（用户、权限、菜单、配置）
  - 各功能模块作为插件注册到平台
  - 支持模块热插拔

### 4.2 系统分层架构
```
前端层 (Vue3)
    ↓
网关层 (Gateway) - 统一认证 / 路由 / 限流
    ↓
服务层 (Service)
    ├─ 核心平台服务
    │  ├─ UserService
    │  ├─ RoleService
    │  ├─ MenuService
    │  ├─ ConfigSvc
    │  ├─ OrgService
    │  ├─ DeptService
    │  ├─ PermService
    │  └─ AuthService
    └─ 功能模块服务 (插件式)
       ├─ 数据库管理模块 (DB Module)
       │  ├─ CompareSvc
       │  ├─ ExcelSvc
       │  ├─ SvnSvc
       │  ├─ NotifySvc
       │  ├─ ScheduleSvc
       │  ├─ SqlGenSvc
       │  └─ StandardSvc
       ├─ 消息队列模块 (MQ Module) - [预留扩展位]
       └─ 配置管理模块 (Config Module) - [预留扩展位]
    ↓
数据访问层 (Data Access)
    └─ 动态数据源路由 (dynamic-datasource)
       ├─ DEV-DBs (7个)
       ├─ SIT-DBs (7个)
       ├─ UAT-DBs (12个)
       └─ Config-DB (1个)
    ↓
外部系统集成
    ├─ SVN
    ├─ 飞秋
    ├─ Nacos
    └─ Nginx
```
