# Word 文档标准化格式提示语模板

> 本模板用于规范基于 Markdown 内容生成 Word（.docx）文档时的完整样式规范。所有样式元素均有明确、可执行的描述，确保生成的 Word 文档格式统一、专业规范。

---

## 一、总体规范

### 1.1 文档基本参数

| 参数项 | 规范值 | 说明 |
|--------|--------|------|
| 纸张大小 | A4（210mm × 297mm） | 标准 A4 纵向 |
| 页边距（上下） | 2.54cm（1英寸） | 标准 1 英寸边距 |
| 页边距（左右） | 2.54cm（1英寸） | 标准 1 英寸边距 |
| 页眉距边界 | 1.5cm | |
| 页脚距边界 | 1.75cm | |
| 默认文字方向 | 从左到右（横向） | |
| 默认字体（中文） | 宋体（SimSun） | 正文中文 |
| 默认字体（英文） | Times New Roman | 正文英文/数字 |
| 默认字号 | 12pt（小四） | 正文标准字号 |

### 1.2 颜色方案

| 颜色类别 | 色值（HEX） | RGB 值 | 用途说明 |
|----------|-------------|---------|----------|
| 主题色 | `#1F3864` | RGB(31, 56, 100) | 封面主标题、一级标题、页眉文字 |
| 辅助色 | `#5B9BD5` | RGB(91, 155, 213) | 副标题、二级标题、超链接 |
| 强调色 | `#C00000` | RGB(192, 0, 0) | 警告信息、重要标注、删除线文本 |
| 表头背景色 | `#D5E8F0` | RGB(213, 232, 240) | 表格表头背景 |
| 代码块背景色 | `#F5F5F5` | RGB(245, 245, 245) | 代码块、引用块背景 |
| 正文文字色 | `#000000` | RGB(0, 0, 0) | 正文标准文字 |
| 次要文字色 | `#595959` | RGB(89, 89, 89) | 页眉页脚、注释、说明文字 |
| 表格边框色 | `#BFBFBF` | RGB(191, 191, 191) | 表格边框线 |
| 深灰色文字 | `#333333` | RGB(51, 51, 51) | 代码块文字 |

## 二、封面设计规范

### 2.1 封面布局

```
┌─────────────────────────────────────────┐
│                                         │
│         （顶部留白约 6cm）                │
│                                         │
│         【主标题】（居中，28pt，主题色）   │
│                                         │
│         【副标题】（居中，16pt，辅助色）   │
│                                         │
│         English Subtitle（斜体，14pt）   │
│                                         │
│         （中部留白约 3cm）                │
│                                         │
│      ┌─────────────────────────┐        │
│      │ 文档版本 │ V1.0.0        │        │
│      │ 发布日期 │ YYYY年MM月    │        │
│      │ 编制单位 │ 【单位名称】  │        │
│      │ 文档密级 │ 内部使用      │        │
│      └─────────────────────────┘        │
│                                         │
│         （底部留白至页脚）                │
│                                         │
└─────────────────────────────────────────┘
```

### 2.2 封面元素样式

| 元素 | 字体 | 字号 | 颜色 | 对齐方式 | 其他 |
|------|------|------|------|----------|------|
| 主标题 | 宋体（中文）/ Arial（英文） | 28pt（约 56 半磅） | 主题色 `#1F3864` | 居中 | 加粗，段后 12pt |
| 副标题 | 宋体 | 16pt（约 32 半磅） | 辅助色 `#5B9BD5` | 居中 | 常规，段后 12pt |
| 英文副标题 | Arial | 14pt（约 28 半磅） | 辅助色 `#5B9BD5` | 居中 | 斜体，段后 60pt |
| 信息表格 | 宋体 | 11pt（约 22 半磅） | 正文色 `#000000` | 居中 | 2 列，无边框或细边框 |

### 2.3 封面信息表格规范

- 表格宽度：约 10cm，居中显示
- 列宽比例：标签列 30%，值列 70%
- 标签列：加粗，居中对齐
- 值列：常规，居中对齐
- 行高：自适应，上下边距各 4pt
- 必填字段：文档版本、发布日期、编制单位、文档密级

## 三、目录生成规则

### 3.1 目录基本规范

| 规范项 | 要求 |
|--------|------|
| 目录标题 | "目  录"（中间双空格），18pt，加粗，居中，段后 18pt |
| 收录层级 | 1-3 级标题（Heading 1 ~ Heading 3） |
| 目录类型 | 自动生成（TOC 字段），支持超链接跳转 |
| 页码对齐 | 右对齐，前导符为点线（......） |
| 更新方式 | 在 Word 中右键 → "更新域" → "更新整个目录" |

### 3.2 目录条目样式

| 层级 | 字体 | 字号 | 缩进 | 颜色 |
|------|------|------|------|------|
| 一级条目 | 宋体 | 12pt | 左缩进 0cm | 主题色 `#1F3864` |
| 二级条目 | 宋体 | 11pt | 左缩进 0.5cm | 正文色 `#000000` |
| 三级条目 | 宋体 | 11pt | 左缩进 1.0cm | 正文色 `#000000` |

### 3.3 目录生成指令

在 docx 生成代码中，使用以下方式插入目录字段：

```javascript
new TableOfContents('Table of Contents', {
  hyperlink: true,
  headingStyleRange: '1-3',
});
```

> **注意**：目录页码需在 Word 中打开文档后手动刷新（`Ctrl+A` → `F9`，或右键目录 → "更新域"）。

| 属性 | 规范值 |
|------|--------|

| 场景 | 处理方式 |

| 右对齐段落 | 设置 `alignment: RIGHT`，取消首行缩进 |

**代码块示例**：

```sql

FROM table_name

  AND condition2 = ?

```

```java
// Java 代码示例
public class DemoHandler {
    @XxlJob("demoJobHandler")
```

### 6.3 强调文本

| 强调类型 | Markdown 语法 | 样式规范 |
|----------|---------------|----------|
| 加粗 | `**文本**` | 加粗，颜色不变 |
| 斜体 | `*文本*` | 斜体，颜色不变 |
| 加粗斜体 | `***文本***` | 加粗 + 斜体 |
| 删除线 | `~~文本~~` | 删除线，强调色 `#C00000` |
| 行内代码 | `` `文本` `` | Courier New，9pt，背景色 `#F5F5F5` |
| 高亮标注 | `==文本==` | 黄色背景（`#FFFF00`），黑色文字 |

```javascript

  alignment: AlignmentType.CENTER,

    new ImageRun({

  alignment: AlignmentType.CENTER,
```

## 十二、Markdown 转 Word 映射规则

### 12.1 元素映射表

| Markdown 元素 | Word 样式 | 说明 |
|---------------|-----------|------|
| `# 一级标题` | Heading 1 | 16pt，加粗，黑色 |
| `## 二级标题` | Heading 2 | 14pt，加粗，黑色 |
| `### 三级标题` | Heading 3 | 12pt，加粗，黑色 |
| `#### 四级标题` | Heading 4 | 11pt，加粗，黑色 |
| 普通段落 | 正文 | 11pt，首行缩进 2 字符 |
| `> 引用` | 引用块 | 10.5pt，灰色，左边框 |
| ```` ``` 代码块 ``` ```` | 代码块 | Courier New 9pt，灰底 |
| `- 列表项` | 无序列表 | 11pt，圆点符号 |
| `1. 列表项` | 有序列表 | 11pt，数字编号 |
| `**加粗**` | 加粗文本 | 加粗 |
| `*斜体*` | 斜体文本 | 斜体 |
| `` `行内代码` `` | 行内代码 | Courier New 9pt |
| `\|表格\|` | 表格 | 表头蓝底，内容 10pt |
| `![图片](url)` | 图片 + 图注 | 居中，图注 9pt |
| `[链接](url)` | 超链接 | 辅助色，下划线 |
| `---` | 分隔线 | 水平线 |

### 12.2 特殊处理规则

1. **中英文混排**：中文用宋体，英文和数字用 Times New Roman，自动切换
2. **数字与单位**：数字与中文之间加半角空格（如"3 年"而非"3年"）
3. **标点符号**：中文段落用全角标点，代码和英文内容用半角标点
4. **空行处理**：Markdown 中的空行在 Word 中转换为段后间距，不产生额外空行
5. **转义字符**：Markdown 转义字符（如 `\*`）在 Word 中显示为普通字符

## 十三、文档结构模板

### 13.1 标准文档结构

```
封面（独立分节，无页眉页脚）
├── 主标题
├── 副标题
├── 英文副标题
```

## 十五、使用说明

### 15.1 应用方式

1. **作为提示语**：将本模板内容作为系统提示语（System Prompt）提供给 AI 助手
2. **结合内容生成**：提供 Markdown 格式的文档内容，AI 按本规范生成 Word 文档
3. **代码生成**：基于本规范编写 docx 生成脚本（如 Node.js + docx 库）

### 15.2 自定义调整

如需调整样式规范，修改以下关键参数：

| 参数 | 位置 | 影响范围 |
|------|------|----------|
| 颜色方案 | 第二节 | 全文档颜色 |
| 字体类型 | 第四节、第五节 | 标题和正文字体 |
| 字号大小 | 第四节、第五节 | 标题和正文字号 |
| 页边距 | 第一节 | 页面布局 |
| 首行缩进 | 第五节 | 正文段落 |

### 15.3 兼容性说明

- 本规范基于 Microsoft Word 2016+ 和 docx-js 库设计
- 字体需在目标系统已安装（宋体、Arial、Times New Roman、Courier New）
- 颜色值使用 HEX 格式，兼容所有主流文档处理工具
- 目录功能需在 Word 中手动刷新才能显示页码
