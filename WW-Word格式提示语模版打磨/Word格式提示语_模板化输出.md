# Word 文档标准化格式提示语（模板化输出）

> 本文档基于 `Word格式提示语.md` 的全部规则内容，按照 `Word格式提示语模板.md` 的结构与表格风格重新组织输出，并完整保留提示语独有的规范（极简模式、字体白名单、标点符号、元数据清除等）。
> **核心定位**：对任意已有 Word 文档进行纯格式标准化处理，绝对保留原始内容。

---

## 一、总体规范

### 1.1 核心执行原则（最高优先级，违反即失败）

| 序号 | 原则内容 |
|------|----------|
| 1 | 绝对保留所有原始文字内容、标点符号、数字、公式、表格数据和图片内容，不得添加、删除、修改、润色或重新组织任何内容 |
| 2 | 绝对不改变原始内容的逻辑顺序、章节结构和段落划分 |
| 3 | 所有格式参数必须精确到小数点后一位，不得使用"约"、"大概"、"适当"等模糊表述 |
| 4 | 整个文档使用统一的格式体系，不得出现任何不一致的地方 |
| 5 | 如遇到本规范未明确规定的情况，按照"最保守、最严谨、最专业"的原则处理 |
| 6 | 本规范适用于所有类型的 Word 文档，包括但不限于：技术方案、设计文档、需求规格、测试报告、商务文档、会议纪要、项目计划、白皮书等 |

### 1.2 文档基本参数

| 参数项 | 规范值 | 说明 |
|--------|--------|------|
| 纸张大小 | A4（210.0mm × 297.0mm），误差 ≤ ±0.1mm | 标准 A4 纵向 |
| 页边距（上） | 2.54cm（1 英寸） | 标准上边距 |
| 页边距（下） | 2.00cm | 标准下边距 |
| 页边距（左，装订侧） | 2.54cm（1 英寸） | 装订侧加宽 |
| 页边距（右） | 2.00cm | 标准右边距 |
| 装订线 | 0.5cm，位置：左侧 | 装订侧边距 |
| 页眉距边界 | 1.50cm | |
| 页脚距边界 | 1.00cm | |
| 页面方向 | 全部纵向，禁止横向 | 超大表格必须拆分为多个纵向表格 |
| 纸张来源 | 默认纸盒 | |
| 打印质量 | 600dpi | 印刷级精度 |
| 打印颜色 | 纯黑白，禁止任何灰度和彩色打印 | 强制单色输出 |
| 页面缩放 | 100%，禁止任何形式的缩放打印 | |

### 1.3 颜色方案（强制纯黑白）

| 颜色类别 | 色值（HEX） | RGB 值 | 用途说明 |
|----------|-------------|---------|----------|
| 正文文字色 | `#000000` | RGB(0, 0, 0) | 所有文字、边框、图片唯一允许颜色 |
| 表头背景色 | `#F2F2F2` | RGB(242, 242, 242) | 表头单元格浅灰背景（唯一允许的非纯黑色） |

> **强制规则**：所有文字颜色必须为纯黑色（RGB:0,0,0），不得使用任何其他颜色；禁止使用任何彩色边框、彩色图片、彩色背景（表头浅灰除外）。

## 二、封面设计规范

### 2.1 封面布局

```
┌─────────────────────────────────────────┐
│                                         │
│         （顶部留白）                      │
│                                         │
│         【主标题】（居中，26.0pt，黑体加粗）│
│                                         │
│         【副标题】（居中，22.0pt，黑体加粗）│
│                                         │
│         （中部留白）                      │
│                                         │
│      ┌─────────────────────────┐        │
│      │ 文档编号/版本号 │ 仿宋_GB2312  │   │
│      │ 作者/日期       │ 宋体 16.0pt  │   │
│      └─────────────────────────┘        │
│                                         │
│         （底部留白至页脚）                │
│                                         │
└─────────────────────────────────────────┘
```

### 2.2 封面元素样式

| 元素 | 中文字体 | 英文字体 | 字号 | 字重 | 颜色 | 对齐方式 |
|------|----------|----------|------|------|------|----------|
| 封面主标题 | 黑体 | Times New Roman | 26.0pt（一号） | 加粗 | 纯黑 `#000000` | 居中 |
| 封面副标题 | 黑体 | Times New Roman | 22.0pt（二号） | 加粗 | 纯黑 `#000000` | 居中 |
| 封面文档编号/版本号 | 仿宋_GB2312 | Times New Roman | 16.0pt（三号） | 常规 | 纯黑 `#000000` | 居中 |
| 封面作者/日期 | 宋体 | Times New Roman | 16.0pt（三号） | 常规 | 纯黑 `#000000` | 居中 |
| 扉页标题 | 黑体 | Times New Roman | 18.0pt（小二号） | 加粗 | 纯黑 `#000000` | 居中 |

### 2.3 封面信息表格规范

- 表格宽度：与页面正文宽度完全一致（16.46cm）
- 表格对齐方式：水平居中对齐
- 单元格内边距：上下 0.1cm，左右 0.15cm
- 单元格垂直对齐：居中
- 保留原始表格的合并/拆分单元格状态，不得修改
- 必填字段：文档编号/版本号、作者/日期

## 十八、使用说明

### 18.1 应用方式

1. **作为提示语**：将本文档内容作为系统提示语（System Prompt）提供给 AI 助手
2. **格式标准化处理**：对任意已有 Word 文档进行纯格式标准化处理
3. **模式选择**：根据场景选择标准模式或极简模式（盲评/匿名文档）

### 18.2 模式选择指南

| 场景 | 推荐模式 | 说明 |
|------|----------|------|
| 正式商务文档 | 标准模式 | 保留完整格式体系 |

| 对外发布文档 | 标准模式 + 元数据清除 | 清除作者/公司等元数据 |
| 需物理打印归档文档 | 标准模式 | 600dpi 纯黑白印刷级输出 |

### 18.3 自定义调整参数

| 参数 | 位置 | 影响范围 |
|------|------|----------|
