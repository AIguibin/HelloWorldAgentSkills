# Excel文件合并与格式优化工具

## 功能概述

此skill用于将多个Excel文件中的指定工作表合并成一个文件，并自动优化格式，包括：
- 合并多个Excel文件的指定工作表（如"目录"表）
- 完整保留原数据的格式（字体、颜色、单元格格式、列宽行高等）
- 自动删除多余的空白行
- 自动删除重复的标题行
- 确保数据完整性和准确性

## 使用场景

适用于以下情况：
- 需要将多个部门或模块的Excel数据表合并成一份总表
- 数据库设计文档的目录表合并
- 多个Excel文件的结构化数据整合
- 需要清理Excel文件中的冗余数据（空白行、重复标题）

## 工作流程

### 第一步：确认需求

在开始处理前，需要确认以下信息：
1. **源文件夹路径**：包含要合并的Excel文件的文件夹路径
2. **目标工作表名称**：要合并的工作表名称（默认为"目录"）
3. **输出文件名称**：合并后的Excel文件名称和保存路径
4. **文件过滤规则**：是否需要过滤特定文件（如临时文件、特定前缀等）

### 第二步：执行合并

使用 `scripts/merge_excel.py` 脚本执行合并操作：

```bash
python scripts/merge_excel.py --folder <文件夹路径> --sheet <工作表名称> --output <输出文件路径>
```

脚本会自动：
- 遍历文件夹中所有Excel文件（.xlsx格式）
- 按文件系统中的自然顺序处理
- 提取每个文件的指定工作表内容
- 合并到一个新文件中，保留所有格式

### 第三步：优化格式

使用 `scripts/optimize_excel.py` 脚本执行格式优化：

```bash
python scripts/optimize_excel.py --file <Excel文件路径>
```

脚本会自动：
- 删除所有空白行
- 删除重复的标题行（保留第一行标题）
- 验证数据完整性

### 第四步：验证结果

合并和优化完成后，需要验证：
1. **数据完整性**：检查所有源文件的数据是否都已合并
2. **格式正确性**：检查字体、颜色、边框等格式是否保留
3. **无重复数据**：确认每个文件只被合并一次
4. **无冗余行**：确认没有空白行和重复标题行

## 核心脚本说明

### merge_excel.py - Excel文件合并脚本

**功能**：
- 合并多个Excel文件的指定工作表
- 保留完整的单元格格式（字体、颜色、边框、对齐方式等）
- 保留列宽和行高
- 保留合并单元格
- 按自然顺序处理文件

**参数**：
- `--folder`: 源文件夹路径（必需）
- `--sheet`: 工作表名称（默认：目录）
- `--output`: 输出文件路径（必需）

**输出**：
- 合并后的Excel文件
- 处理统计信息（文件数量、行数等）

### optimize_excel.py - Excel格式优化脚本

**功能**：
- 删除空白行
- 删除重复标题行
- 验证数据完整性
- 生成优化报告

**参数**：
- `--file`: Excel文件路径（必需）

**输出**：
- 优化后的Excel文件
- 优化统计信息（删除行数、剩余行数等）

## 最佳实践

### 文件命名规范
- 使用有意义的文件名，如：`新信贷_数据库设计_全量信贷v1.0.0.xlsx`
- 包含版本号，便于版本管理
- 避免使用特殊字符

### 数据验证
- 合并前检查源文件是否完整
- 合并后验证数据行数是否正确
- 检查关键列的数据是否完整

### 格式保留
- 使用openpyxl库确保格式完整保留
- 避免使用pandas等会丢失格式的库
- 注意合并单元格的处理

### 性能优化
- 对于大文件，考虑分批处理
- 使用进度显示，便于监控处理进度
- 处理大量文件时，注意内存使用

## 常见问题

### Q1: 为什么有些格式丢失了？
A: 确保使用openpyxl库而不是pandas，pandas会丢失大部分格式信息。

### Q2: 如何处理不同列数的Excel文件？
A: 脚本会自动适应不同的列数，但建议源文件保持相同的列结构。

### Q3: 合并后的文件太大怎么办？
A: 可以考虑：
- 分批处理文件
- 删除不必要的工作表
- 使用Excel的压缩功能

### Q4: 如何避免重复合并？
A: 脚本会记录已处理的文件，确保每个文件只被合并一次。

## 示例用法

### 示例1：合并数据库设计文档

```bash
# 合并所有数据库设计文档的目录表
python scripts/merge_excel.py \
  --folder "e:\WorkSpace\数据库设计文档" \
  --sheet "目录" \
  --output "e:\WorkSpace\数据库设计文档\全量数据库设计v1.0.0.xlsx"

python scripts/optimize_excel.py \
  --file "e:\WorkSpace\数据库设计文档\全量数据库设计v1.0.0.xlsx"
```

### 示例2：合并多个部门的数据表

```bash

python scripts/merge_excel.py \
  --folder "/data/departments" \
  --sheet "数据汇总" \
  --output "/data/merged/全公司数据汇总.xlsx"

# 优化格式
python scripts/optimize_excel.py \
  --file "/data/merged/全公司数据汇总.xlsx"
```

## 技术细节

### 依赖库
- openpyxl: 用于读写Excel文件，保留格式
- Python 3.6+: 脚本运行环境

### 格式保留机制
- 字体样式：Font对象复制
- 单元格填充：PatternFill对象复制
- 边框样式：Border对象复制
- 对齐方式：Alignment对象复制
- 列宽行高：维度对象复制
- 合并单元格：范围调整和复制

### 数据验证机制
- 行数统计：验证合并前后行数一致性
- 空白行检测：检查所有单元格是否为空
- 重复标题检测：比较行内容与第一行标题
- 数据完整性：检查关键列的数据

## 注意事项

1. **备份原文件**：处理前建议备份原始Excel文件
2. **文件权限**：确保有读写权限
3. **内存占用**：大文件处理可能占用较多内存
4. **处理时间**：大量文件合并可能需要较长时间
5. **格式兼容性**：确保所有源文件使用相同的Excel版本格式

## 输出报告

处理完成后会生成详细报告，包括：
- 处理的文件列表
- 每个文件的数据行数
- 删除的空白行数量
- 删除的重复标题行数量
- 最终文件的总行数
- 数据预览（前5行和最后5行）
